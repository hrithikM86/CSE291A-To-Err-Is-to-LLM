Algorithm:

1. Check if the input list `strings` is empty.
   - If true, return `None`.
2. Initialize `longest_string` to `None` and `max_length` to 0.
3. Iterate through each string `s` in `strings`:
   - If `s` is longer than `max_length`, update `longest_string` to `s` and `max_length` to the length of `s`.
4. Return `longest_string`.

Edge Cases:
- An empty list should return `None`.
- A list with a single string should return that string.
- A list with multiple strings of the same maximum length should return the first one.

Complexity:
- Time: O(n), where n is the number of strings in the list.
- Space: O(1), as only a few variables are used.
