Algorithm:

1. Convert the input string to lowercase to ensure case insensitivity.
2. Initialize an empty set to store unique characters.
3. Iterate through each character in the string:
   - If the character is not already in the set, add it.
4. Return the size of the set as the result.

Edge Cases:
- Empty string: Return 0.
- String with only one character: Return 1.
- String with all characters being the same: Return 1.
- String with only spaces: Return 0.

Complexity:
- Time Complexity: O(n), where n is the length of the string.
- Space Complexity: O(1), as the set size is bounded by the number of unique characters in the alphabet (26 for English).
