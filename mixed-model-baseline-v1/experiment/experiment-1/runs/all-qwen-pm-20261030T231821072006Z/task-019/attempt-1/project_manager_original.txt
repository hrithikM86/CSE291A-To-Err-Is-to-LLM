### Implementation Checklist for `sort_numbers(numbers: str) -> str`

1. **Function Signature**
   - Define the function `sort_numbers(numbers: str) -> str`.

2. **Edge Cases**

3. **Mapping Number Words to Numerical Values**
   - Create a dictionary to map number words to their numerical values:
     ```python
     number_map = {'zero': 0, 'one': 1, 'two': 2, 'three': 3, 'four': 4, 'five': 5, 'six': 6, 'seven': 7, 'eight': 8, 'nine': 9}
     ```

4. **Splitting the Input String**
   - Split the input string into a list of number words using `split()`.

5. **Filtering Invalid Number Words**
   - Filter out any number words that are not in the `number_map`.

6. **Converting and Sorting Numerical Values**
   - Convert the valid number words to their numerical values.
   - Sort the numerical values.

7. **Converting Back to Number Words**
   - Convert the sorted numerical values back to number words using the `number_map`.

8. **Joining and Returning the Result**
   - Join the sorted number words with spaces and return the result.

1. Check if the input string is empty. If so, return an empty string.
