Algorithm for `largest_divisor(n: int) -> int:`:

1. **Input Validation**: Check if `n` is less than or equal to 1. If true, return `None`.
2. **Edge Case Handling**: If `n` is negative, convert it to its positive counterpart.
3. **Finding the Largest Divisor**:
   - Start from `n // 2` and decrement by 1 until 1.
   - For each number `i`, check if `n % i == 0`.
   - Return the first `i` that satisfies the condition.
4. **Return the Result**: If no divisor is found, return `1` (though this should not happen given the algorithm).

Complexity:
- Time: O(n) in the worst case, where `n` is the input number.
- Space: O(1), as no additional space is used.

This algorithm ensures that the function correctly handles all specified edge cases, including negative numbers and the special case where `n` is 1 or less.
