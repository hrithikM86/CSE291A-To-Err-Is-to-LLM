Requirements:
- **Inputs**: 
  - `strings`: A list of strings.
  - `prefix`: A string representing the prefix to filter by.
- **Outputs**: 
  - A list of strings that start with the given prefix.
- **Behavior**:
  - Return an empty list if the input list is empty.
  - Strings in the output list must start exactly with the given prefix.
- **Edge Cases**:
  - An empty input list should return an empty list.
  - The prefix can be an empty string, which should return the original list.
  - The input list can contain strings of varying lengths, including the prefix length.
