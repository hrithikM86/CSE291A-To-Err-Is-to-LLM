Algorithm for `encode_cyclic`:

1. **Initialization**: 
   - Check if the input string `s` is empty or has less than three characters. If so, return `s` as is.

2. **Grouping**:
   - Split the string into groups of three characters using a list comprehension. Each group is defined as `s[(3 * i):min((3 * i + 3), len(s))]` for `i` in range `((len(s) + 2) // 3)`.

3. **Cycling**:
   - For each group, if it has exactly three characters, cyclically shift it by moving the first character to the end. Otherwise, leave it unchanged.

4. **Joining**:
   - Join the modified groups back into a single string and return it.

Algorithm for `decode_cyclic`:

1. **Initialization**:
   - Check if the input string `s` is empty or has less than three characters. If so, return `s` as is.

2. **Grouping**:
   - Split the string into groups of three characters using a similar list comprehension as in `encode_cyclic`.

3. **Decycling**:
   - For each group, if it has exactly three characters, cyclically shift it back by moving the last character to the beginning. Otherwise, leave it unchanged.

4. **Joining**:
   - Join the modified groups back into a single string and return it.

Edge Cases:
- Empty string or strings with less than three characters should be handled by returning the string unchanged.
- Strings with lengths not divisible by three should be correctly grouped and processed.

Complexity:
- Both functions have a time complexity of O(n), where n is the length of the input string, due to the single pass required for grouping and processing.
