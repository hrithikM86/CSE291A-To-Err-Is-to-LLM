Algorithm for `pairs_sum_to_zero(l)`:

1. Check if the list `l` has less than 2 elements. If so, return `False`.
2. Use a set to store seen numbers.
3. Iterate through each number `num` in the list:
   - Check if `-num` is in the set of seen numbers.
   - If found, return `True`.
   - Otherwise, add `num` to the set of seen numbers.
4. If no such pair is found after the loop, return `False`.

Edge cases:
- An empty list or a list with a single element should return `False`.
- Duplicates do not affect the result; only the presence of a pair that sums to zero matters.

Complexity:
- Time: O(n), where n is the number of elements in the list.
- Space: O(n) for the set used to store seen numbers.
