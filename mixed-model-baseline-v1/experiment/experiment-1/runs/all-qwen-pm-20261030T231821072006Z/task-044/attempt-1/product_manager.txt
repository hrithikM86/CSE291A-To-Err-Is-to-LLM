Requirements:
- The function `change_base` takes two parameters: `x` (an integer) and `base` (an integer less than 10).
- It returns a string representing the number `x` converted to the specified `base`.
- The input `base` must be between 2 and 9 inclusive.
- Handle cases where `x` is 0, returning '0'.
- Handle negative values of `x` by converting the absolute value and adding a '-' sign to the result.
- Ensure the function raises a `ValueError` if `base` is not between 2 and 9.
- No edge cases beyond the constraints are expected, as the base is strictly less than 10.
