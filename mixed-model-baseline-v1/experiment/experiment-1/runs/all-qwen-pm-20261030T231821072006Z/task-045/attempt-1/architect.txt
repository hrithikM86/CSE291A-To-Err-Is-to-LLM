Algorithm for `triangle_area(a, h)`:

1. Validate inputs:
   - Check if `a` or `h` is negative.
   - If either is negative, return "Invalid input: side and height must be non-negative."

2. Check for edge cases:
   - If `a` or `h` is zero, return 0.0.

3. Calculate the area:
   - Use the formula: `area = 0.5 * a * h`
   - Return the calculated area.

Complexity:
- The algorithm has a constant time complexity O(1) as it involves a fixed number of operations regardless of the input size.

Edge Cases Handled:
- Negative values for `a` or `h` result in an error message.
- Zero values for `a` or `h` result in an area of 0.0.
