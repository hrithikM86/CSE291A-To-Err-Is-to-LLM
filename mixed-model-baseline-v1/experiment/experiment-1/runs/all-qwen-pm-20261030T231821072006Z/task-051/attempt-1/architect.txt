Algorithm for `remove_vowels(text)`:

1. Define the function `remove_vowels(text)`.
2. Initialize an empty string `result`.
3. Iterate through each character `c` in `text`:
   - If `c` is not a vowel (i.e., not 'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U'):
     - Append `c` to `result`.
4. Return `result`.

Edge cases:
- If `text` is an empty string, return an empty string.
- If `text` contains only vowels, return an empty string.
- If `text` contains no vowels, return the original string.

Complexity:
- Time: O(n), where n is the length of the input string.
- Space: O(n), for storing the resulting string.
