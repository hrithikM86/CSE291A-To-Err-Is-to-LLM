Requirements:
- The function `add` takes two integer inputs, `x` and `y`.
- It returns the sum of `x` and `y` as an integer.
- The function should handle non-negative integers.
- Edge cases:
  - If either `x` or `y` is 0, return the non-zero value.
  - If both `x` and `y` are 0, return 0.
- The function should raise a `TypeError` if either input is not an integer.
