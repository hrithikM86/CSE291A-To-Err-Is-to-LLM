Requirements:
- Function `same_chars` takes two strings `s0` and `s1` as input.
- Returns `True` if both strings contain exactly the same set of characters, regardless of order or frequency.
- Returns `False` otherwise.
- Consider only unique characters in the comparison.
- Edge cases:
  - Empty strings: Return `True`.
  - Different lengths: Return `False`.
  - Special characters and numbers: Include in the comparison.
- No spaces or case sensitivity: Treat them as part of the comparison.
