Algorithm for `sum_to_n(n: int)`:

1. Validate input `n` to ensure it is within the range [1, 10000].
2. If `n` is 1, return 1 (edge case).
3. Use the formula `n * (n + 1) // 2` to calculate the sum.
4. Return the calculated sum.

Complexity:
- Time Complexity: O(1) - The operation is constant time.
- Space Complexity: O(1) - No additional space is used.

Edge Cases:
- `n = 1` should return 1.
- `n` within the range [1, 10000] should return the correct sum.
- `n` outside the range [1, 10000] should not be handled, as per the specification.
