Algorithm for `fibfib(n)`:

1. **Input Validation**: Check if `n` is less than 0. If true, raise `ValueError`.
2. **Base Cases**:
   - If `n == 0` or `n == 1`, return `0`.
   - If `n == 2`, return `1`.
3. **Dynamic Programming with Memoization**:
   - Use a dictionary `memo` to store previously computed values.
   - If `n` is not in `memo`, compute `fibfib(n)` using the formula `fibfib(n-1) + fibfib(n-2) + fibfib(n-3)`.
   - Store the result in `memo` for future use.
4. **Return the Result**: Return the computed value.

Edge Cases:
- Ensure the function handles `n < 0` by raising `ValueError`.

Complexity:
- Time Complexity: O(n) due to memoization.

This approach ensures efficient computation even for large values of `n`.
