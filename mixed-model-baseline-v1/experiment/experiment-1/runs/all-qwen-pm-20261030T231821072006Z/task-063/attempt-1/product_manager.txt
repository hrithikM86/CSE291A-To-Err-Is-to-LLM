Requirements:
- Implement the `fibfib` function that takes an integer `n` as input.
- Compute the n-th element of the FibFib number sequence.
- Follow the defined sequence rules:
  - `fibfib(0) == 0`
  - `fibfib(1) == 0`
  - `fibfib(2) == 1`
  - `fibfib(n) == fibfib(n-1) + fibfib(n-2) + fibfib(n-3)` for `n > 2`.
- Handle edge cases where `n` is less than 0 by raising a `ValueError`.
- Ensure the function is efficient for large values of `n` (consider using memoization or dynamic programming).
- Return an integer as the result.
- Test the function with provided examples:
  - `fibfib(1)` should return `0`
  - `fibfib(5)` should return `4`
  - `fibfib(8)` should return `24`
