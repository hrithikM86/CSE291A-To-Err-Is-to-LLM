Requirements:
- **Inputs**: 
  - `x`: An integer.
  - `shift`: An integer representing the number of positions to shift the digits to the right.
- **Outputs**: 
  - A string representing the circularly shifted integer.
- **Behavior**:
  - Shift the digits of `x` to the right by `shift` positions.
  - If `shift` is greater than the number of digits in `x`, return the digits of `x` reversed as a string.
- **Edge Cases**:
  - If `x` is 0 or `shift` is 0, return "0".
  - If `x` is negative, treat it as its absolute value and append a '-' to the result.
  - Ensure the result is a string.
