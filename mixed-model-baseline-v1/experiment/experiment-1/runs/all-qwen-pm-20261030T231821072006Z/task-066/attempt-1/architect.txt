Algorithm:

1. Initialize `sum` to 0.
2. For each character `c` in the input string `s`:
   - If `c` is an uppercase letter (ASCII 65-90):
     - Add the ASCII value of `c` to `sum`.
3. Return `sum`.

Edge Cases:
- An empty string: Return 0.
- Strings with no uppercase letters: Return 0.
- Mixed case strings: Only consider uppercase letters.

Complexity:
- Time: O(n), where n is the length of the string.
- Space: O(1), constant space used.
