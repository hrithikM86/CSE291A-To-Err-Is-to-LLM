Requirements:
- **Input**: A single string `s`.
- **Output**: An integer representing the sum of the ASCII codes of the uppercase characters in the input string.
- **Behavior**:
  - Sum only the ASCII codes of characters that are uppercase letters (A-Z).
  - Ignore any other characters.
- **Edge Cases**:
  - An empty string should return `0`.
  - Strings with no uppercase letters should return `0`.
  - Mixed case strings should only consider uppercase letters.
