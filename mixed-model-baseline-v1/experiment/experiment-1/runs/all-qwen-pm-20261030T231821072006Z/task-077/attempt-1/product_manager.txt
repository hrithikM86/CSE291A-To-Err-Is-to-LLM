Requirements:
- The function `iscube(a)` takes an integer `a` as input.
- It returns `True` if `a` is a perfect cube of some integer number.
- It returns `False` otherwise.
- The function should handle both positive and negative integers, including zero.
- Examples:
  - `iscube(1)` -> `True`
  - `iscube(2)` -> `False`
  - `iscube(-1)` -> `True`
  - `iscube(64)` -> `True`
  - `iscube(0)` -> `True`
  - `iscube(180)` -> `False`
