Requirements:
- The function `hex_key` takes a single input `num` (a string representing a hexadecimal number).
- The function returns an integer representing the count of hexadecimal digits that are prime numbers.
- Prime hexadecimal digits are: 2, 3, 5, 7, B (11), D (13).
- The input string `num` is assumed to be valid or an empty string.
- Hexadecimal symbols A, B, C, D, E, F are always uppercase.
- Examples:
  - `hex_key("AB")` returns 1.
  - `hex_key("1077E")` returns 2.
  - `hex_key("ABED1A33")` returns 4.
  - `hex_key("123456789ABCDEF0")` returns 6.
  - `hex_key("2020")` returns 2.
