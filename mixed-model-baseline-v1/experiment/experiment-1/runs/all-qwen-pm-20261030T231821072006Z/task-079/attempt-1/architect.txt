Algorithm for `decimal_to_binary(decimal)`:

1. Validate input: Ensure `decimal` is a non-negative integer.
2. Handle edge case: If `decimal` is 0, return "db0db".
3. Convert `decimal` to binary:
   - Initialize an empty string `binary`.
   - While `decimal` is greater than 0:
     - Append `decimal % 2` to `binary`.
     - Divide `decimal` by 2 (integer division).
   - Reverse `binary` to get the correct binary representation.
4. Enclose `binary` with 'db' at the start and end.
5. Return the resulting string.

Complexity:
- Time: O(log(decimal)), where log is base 2.
- Space: O(log(decimal)), for storing the binary string.

This algorithm ensures the correct conversion and handles all specified edge cases.
