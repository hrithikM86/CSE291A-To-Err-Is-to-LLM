Requirements:
- **Inputs**: A list of non-negative integers.
- **Outputs**: A new list, sorted based on the specified conditions.
- **Behavior**:
  - If the sum of the first and last elements is odd, sort the list in ascending order.
  - If the sum is even, sort the list in descending order.
  - Return a copy of the sorted list.
- **Edge Cases**:
  - An empty list should return an empty list.
  - A list with a single element should return the same element.
  - Lists with multiple elements should be sorted according to the sum condition.
