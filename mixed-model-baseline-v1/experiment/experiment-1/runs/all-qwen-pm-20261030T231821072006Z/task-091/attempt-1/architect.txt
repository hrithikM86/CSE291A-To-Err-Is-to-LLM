Algorithm for `is_bored(S)`:

1. **Initialization**:
   - Set `boredom_count` to 0.
   - Split the string `S` into sentences using `'. '?!'` as delimiters.

2. **Iterate through sentences**:
   - For each sentence, strip leading and trailing punctuation.
   - Check if the sentence starts with the exact string "I ".
     - If it does, increment `boredom_count`.

3. **Return the result**:
   - Return `boredom_count`.

**Edge Cases**:
- Handle empty string: Return 0.
- Handle multiple delimiters: Split correctly.
- Handle leading or trailing punctuation: Strip appropriately.

**Complexity**:
- Time: O(n), where n is the length of the string `S`.
- Space: O(n), for storing the split sentences.
