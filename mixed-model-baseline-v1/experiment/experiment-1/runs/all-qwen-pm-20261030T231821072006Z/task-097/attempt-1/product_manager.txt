Requirements:
- The function `multiply(a, b)` takes two integer inputs.
- It returns the product of the unit digits of the input integers.
- The function should handle both positive and negative integers.
- Edge cases:
  - If either input is 0, the function returns 0.
  - If both inputs are 0, the function returns 0.
  - If one input is negative and the other is positive, the function still returns the product of their unit digits.
- Examples:
  - `multiply(148, 412)` returns `16`.
  - `multiply(19, 28)` returns `72`.
  - `multiply(2020, 1851)` returns `0`.
  - `multiply(14, -15)` returns `20`.
