Requirements:
- **Input**: A single string `s`.
- **Output**: An integer representing the number of uppercase vowels ('A', 'E', 'I', 'O', 'U') found at even indices in the string `s`.
- **Behavior**:
  - Count only characters at even indices (0, 2, 4, ...).
  - Uppercase vowels are the only characters to be counted.
- **Edge Cases**:
  - Empty string: Return 0.
  - String with no even indices: Return 0.
  - String with only lowercase letters: Return 0.
  - String with only uppercase vowels at even indices: Return the count of such vowels.
