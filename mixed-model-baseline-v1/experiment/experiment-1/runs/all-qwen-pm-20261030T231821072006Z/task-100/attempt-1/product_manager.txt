Requirements:
- **Input**: A positive integer `n` (1 ≤ n ≤ 1000).
- **Output**: A list of integers where each element represents the number of stones in each level of the pile.
- **Behavior**:
  - The first level has `n` stones.
  - For subsequent levels, if the current level's stone count is odd, the next level has the next odd number of stones.
  - If the current level's stone count is even, the next level has the next even number of stones.
- **Edge Cases**:
  - If `n` is 1, return `[1]`.
  - If `n` is even, the last level will also be even.
  - If `n` is odd, the last level will be odd.
