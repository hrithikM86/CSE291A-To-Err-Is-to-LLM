Requirements:
- The function `count_nums` takes a single input `arr`, which is a list of integers.
- It returns an integer representing the count of elements in `arr` whose sum of digits is greater than 0.
- If a number is negative, its first digit is considered negative.
- Edge cases:
  - `arr` is an empty list: return 0.
  - `arr` contains only negative numbers with a single digit: return 0.
  - `arr` contains a mix of positive, negative, and zero values: correctly count elements based on the sum of their digits.
