Algorithm for `select_words(s, n)`:

1. Define a helper function `count_consonants(word)` that returns the number of consonants in a word.
2. Initialize an empty list `result` to store the words that match the criteria.
3. Split the input string `s` into words.
4. Iterate over each word in the list:
   - If the word is not empty and `count_consonants(word) == n`, add the word to `result`.
5. Return `result`.

Edge cases:
- Empty string: Return an empty list.
- Single character words: Consider them as words with 0 consonants if they are not vowels.
- Vowel-only words: These should not be included in the result.

Complexity:
- Time: O(m * k), where m is the number of words in the string and k is the average length of the words.
- Space: O(m) for storing the result list.
