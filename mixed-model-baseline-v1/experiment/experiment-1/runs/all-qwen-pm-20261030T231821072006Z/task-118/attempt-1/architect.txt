Algorithm for `get_closest_vowel(word)`:

1. **Input Validation**: 
   - If `word` is empty, return an empty string.

2. **Initialize Variables**:
   - `n` = length of `word`
   - `closest_vowel` = empty string

3. **Iterate from Right to Left**:
   - For `i` from `n-2` to `0` (inclusive):
     - Check if `word[i]` is a vowel and `word[i+1]` is a consonant.
     - If true, set `closest_vowel` to `word[i]` and break the loop.

4. **Return Result**:
   - Return `closest_vowel`.

**Edge Cases**:
- Handle empty string: Return an empty string.
- Handle single character: Return an empty string.
- Handle no valid vowels: Return an empty string.
- Handle vowels at the beginning or end: Return an empty string.

**Complexity**:
- Time: O(n), where n is the length of the word.
- Space: O(1), constant space used.
