Requirements:
- Implement `maximum(arr, k)` where `arr` is a list of integers and `k` is a positive integer.
- Return a sorted list of length `k` containing the `k` largest numbers from `arr`.
- The input list `arr` will have a length between 1 and 1000, and its elements will range from -1000 to 1000.
- If `k` is 0 or greater than the length of `arr`, return an empty list.
- If `k` is equal to the length of `arr`, return the sorted `arr`.
- Handle cases where `arr` contains duplicate numbers.
- Edge cases: 
  - Empty list input: Return an empty list.
  - `k` is 0: Return an empty list.
  - `k` is equal to the length of `arr`: Return the sorted `arr`.
