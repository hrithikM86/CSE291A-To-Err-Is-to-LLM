Requirements:
- **Inputs**: 
  - `arr`: A non-empty list of integers.
  - `k`: An integer where `1 <= k <= len(arr)`.
- **Outputs**: 
  - An integer representing the sum of elements with at most two digits from the first `k` elements of `arr`.
- **Behavior**:
  - Sum elements in `arr` that have at most two digits from the first `k` elements.
- **Edge Cases**:
  - If `k` is 1, return the first element if it has at most two digits.
  - If no elements with at most two digits are found in the first `k` elements, return 0.
  - If `arr` contains only elements with more than two digits, return 0.
