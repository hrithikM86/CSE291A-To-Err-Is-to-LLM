Requirements:
- Input: A list of integers (`lst`).
- Output: A boolean value indicating whether the list is sorted in ascending order.
- Behavior: 
  - Return `True` if the list is sorted in ascending order.
  - Return `False` if the list is not sorted in ascending order or if there are more than one consecutive duplicate elements.
- Edge Cases:
  - An empty list returns `True`.
  - A list with a single element returns `True`.
  - A list with consecutive duplicates (e.g., `[1, 1, 2, 3]`) returns `False`.
  - Negative numbers are not expected, so they should not be present in the input.
