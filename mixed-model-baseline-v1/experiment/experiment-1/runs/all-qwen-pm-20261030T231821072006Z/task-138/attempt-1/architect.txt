Algorithm for `is_equal_to_sum_even(n)`:

1. **Input Validation**: Ensure `n` is within the range [1, 10000].
2. **Edge Cases**:
   - If `n < 8`, return `False`.
   - If `n % 2 != 0`, return `False`.
3. **General Case**:
   - If `n == 8`, return `True`.
   - For `n > 8`, check if `(n - 8) % 2 == 0` and `(n - 8) >= 0`. If true, return `True`; otherwise, return `False`.

Complexity:
- Time: O(1) - The operations are constant time.
- Space: O(1) - No additional space is used beyond a few variables.
