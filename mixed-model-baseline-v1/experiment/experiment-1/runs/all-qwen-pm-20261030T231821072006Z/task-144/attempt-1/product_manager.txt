Requirements:
- The function `simplify(x, n)` takes two string inputs, `x` and `n`, representing fractions.
- Each fraction is in the format `<numerator>/<denominator>`, where both parts are positive whole numbers.
- The function returns `True` if the product of the two fractions is a whole number, otherwise `False`.
- Ensure the function handles valid fractions without zero denominators.
- Consider edge cases like `1/1` and `2/2`.

Example inputs and outputs:
- `simplify("1/5", "5/1")` should return `True`.
- `simplify("1/6", "2/1")` should return `False`.
- `simplify("7/10", "10/2")` should return `False`.
