Requirements:
- **Input**: A list of integers (`nums`).
- **Output**: An integer representing the count of numbers greater than 10 with both first and last digits being odd (1, 3, 5, 7, 9).
- **Behavior**:
  - Check if each number is greater than 10.
  - Extract the first and last digits of the number.
  - Verify if both digits are odd.
- **Edge Cases**:
  - Empty list: Return 0.
  - List with no numbers > 10: Return 0.
  - Negative numbers: Consider their absolute value for digit extraction.
  - Single-digit numbers: Ignore as they are not greater than 10.
