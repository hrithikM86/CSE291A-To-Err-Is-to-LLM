Requirements:
- **Inputs**: Two positive integers `a` and `b`.
- **Outputs**: A list of even digits between `a` and `b` (inclusive) in ascending order.
- **Behavior**:
  - If `a` and `b` are equal, return an empty list if both are not even digits.
  - If `a` > `b`, return the same list as if `a` < `b`.
  - Include only even digits (0, 2, 4, 6, 8) in the output.
- **Edge Cases**:
  - If `a` or `b` is 0, ensure it is not included in the output.
  - If `a` and `b` are the same and both are even, return `[a]`.
  - If `a` and `b` are the same and both are odd, return an empty list.
