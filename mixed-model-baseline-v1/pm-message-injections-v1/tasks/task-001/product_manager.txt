Requirements:
- The function `separate_paren_groups` takes a single input `paren_string` (type: `str`).
- The input string contains multiple groups of nested parentheses that are balanced and not nested within each other.
- Spaces in the input string should be ignored.
- The function returns a list of strings, where each string represents a separate group of parentheses.
- The order of the groups in the output list should match their order in the input string.
- Edge cases:
  - Empty input string: return an empty list.
  - Single group: return a list containing the single group.
  - Multiple groups: correctly separate and return each group.
  - Unbalanced or nested groups: ignore them and only return balanced, non-nested groups.
