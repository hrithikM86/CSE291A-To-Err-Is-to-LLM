Requirements:
- **Inputs**: A list of integers (`numbers: List[int]`).
- **Outputs**: A list of integers representing the rolling maximum values found until each position in the input list (`List[int]`).
- **Behavior**:
  - For each position in the input list, return the maximum value found from the start of the list up to and including the current position.
  - The output list should have the same length as the input list.
- **Edge Cases**:
  - If the input list is empty, return an empty list.
  - If the input list contains only one element, return a list with that single element.
