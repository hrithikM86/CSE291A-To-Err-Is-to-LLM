Algorithm for `all_prefixes`:

1. Initialize an empty list `prefixes`.
2. If the input string is empty, return `prefixes` (which is an empty list).
3. For each index `i` from 0 to the length of the string (inclusive):
   - Append the substring from the start to index `i` to `prefixes`.
4. Return the list `prefixes`.

Edge cases:
- If the input string is empty, return an empty list.
- If the input string is a single character, return a list containing the string and an empty string.

Complexity:
- Time: O(n^2) due to substring operations in the loop.
- Space: O(n) for storing the list of prefixes, where n is the length of the input string.
