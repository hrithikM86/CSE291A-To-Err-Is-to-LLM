Requirements:
- The function `parse_music` takes a single input `music_string` (str).
- The function returns a list of integers.
- Each character in `music_string` corresponds to a musical note with a specific duration:
  - 'o' = 4 beats (whole note)
  - 'o|' = 2 beats (half note)
  - '.|' = 1 beat (quarter note)
- The function should correctly parse the input string and return a list of integers representing the duration of each note.
- Edge cases:
  - Empty input string should return an empty list.
  - Invalid characters in the input string should be ignored, and parsing should continue with valid notes.
