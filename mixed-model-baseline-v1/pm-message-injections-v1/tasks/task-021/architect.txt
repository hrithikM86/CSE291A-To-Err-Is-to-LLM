Algorithm:

1. Validate input: Ensure the list has at least two elements.
2. Find the minimum and maximum values in the list.
3. For each number in the list, apply the linear transformation formula:
   \[ \text{transformed\_value} = \frac{\text{number} - \text{min\_value}}{\text{max\_value} - \text{min\_value}} \]
4. Return the transformed list.

Complexity:
- Time: O(n), where n is the number of elements in the list (due to finding min and max and iterating through the list).
- Space: O(n), for storing the transformed list.

Edge Cases:
- Handling lists with duplicate values.
- Lists containing negative numbers.
- Lists containing zero.
- Lists with the minimum and maximum values being the same (rare but possible).
