Algorithm:

1. Initialize an empty list `result` to store the final output.
2. Initialize an empty dictionary `seen` to keep track of seen elements.
3. Iterate through each number in the input list `numbers`:
   - If the number is not in `seen`:
     - Add the number to `result`.
     - Add the number to `seen`.
4. Return `result`.

Edge Cases:
- An empty list: Return an empty list.
- A list with no duplicates: Return the same list.
- A list with all elements being the same: Return a list with one instance of that element.

Complexity:
- Time Complexity: O(n), where n is the number of elements in the input list.
- Space Complexity: O(n), for storing the `seen` dictionary and the `result` list.
