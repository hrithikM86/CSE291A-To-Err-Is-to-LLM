Requirements:
- Input: A single string `string` of any length.
- Output: A new string where all lowercase letters are converted to uppercase and all uppercase letters are converted to lowercase.
- Behavior: The function should iterate through each character in the input string, check its case, and swap it accordingly.
- Edge Cases:
  - Empty string: Return an empty string.
  - String with no alphabetic characters: Return the original string.
  - String with mixed case: Correctly flip the case of each alphabetic character.
