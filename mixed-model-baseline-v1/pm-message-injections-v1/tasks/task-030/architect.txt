Algorithm for `get_positive`:

1. Initialize an empty list `positive_nums` to store the positive numbers.
2. Iterate through each number `num` in the input list `l`.
3. If `num` is greater than 0, append `num` to `positive_nums`.
4. Return `positive_nums`.

Edge Cases:
- If `l` is empty, return an empty list.
- If `l` contains no positive numbers, return an empty list.
- If `l` contains all positive numbers, return `l` as is.

Complexity:
- Time Complexity: O(n), where n is the length of the list `l`.
- Space Complexity: O(k), where k is the number of positive numbers in the list `l`.
