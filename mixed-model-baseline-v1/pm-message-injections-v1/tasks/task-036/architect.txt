Algorithm for `fizz_buzz(n: int)`:

1. Validate input `n`:
   - If `n < 1` or `n > 10000`, return an error message or raise an exception.
2. Initialize a counter `count` to 0.
3. For each integer `i` from 1 to `n-1`:
   - If `i % 11 == 0` or `i % 13 == 0`:
     - Convert `i` to a string and count occurrences of '7'.
     - Add the count to `count`.
4. Return `count`.

Edge Cases:
- If `n` is less than 1 or greater than 10000, raise an exception or return an error message.
- Handle large numbers efficiently by avoiding unnecessary string conversions and operations.

Time Complexity: O(n * d), where `d` is the average number of digits in numbers less than `n` that are divisible by 11 or 13.
Space Complexity: O(1) - constant space is used.
