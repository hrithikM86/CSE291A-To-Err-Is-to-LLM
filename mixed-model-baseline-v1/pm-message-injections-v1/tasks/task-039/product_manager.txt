Requirements:
- The function `prime_fib(n: int)` should return the n-th Fibonacci number that is also prime.
- Input: `n` (1 ≤ n ≤ 20) - an integer representing the position in the sequence.
- Output: An integer - the n-th prime Fibonacci number.
- Edge Cases:
  - If `n` is 1, return 2.
  - If `n` is 2, return 3.
  - For `n` > 20, return an appropriate error message or handle it as specified (e.g., raise an exception or return None).
- Note: Ensure the function handles invalid inputs gracefully (e.g., negative numbers, non-integers).
