Requirements:
- The function `pairs_sum_to_zero(l)` takes a single input `l`, which is a list of integers.
- It returns `True` if there are at least two distinct elements in the list that sum to zero.
- It returns `False` if no such pair exists or if the list has less than two elements.
- Edge cases:
  - An empty list or a list with a single element should return `False`.
  - Duplicates do not affect the result; only the presence of a pair that sums to zero matters.
