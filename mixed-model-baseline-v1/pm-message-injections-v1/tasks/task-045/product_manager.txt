Requirements:
- Function: `triangle_area(a, h)`
- Inputs:
  - `a`: Length of a side of the triangle (float or int)
  - `h`: Height of the triangle (float or int)
- Output:
  - Area of the triangle (float)
- Behavior:
  - Calculate the area using the formula: `0.5 * a * h`
- Edge Cases:
  - If `a` or `h` is negative, return an error message: "Invalid input: side and height must be non-negative."
  - If `a` or `h` is zero, return 0.0.
