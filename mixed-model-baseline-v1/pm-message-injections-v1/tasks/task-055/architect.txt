Algorithm for `fib(n: int)`:

1. **Input Validation**: Check if `n < 1`. If true, raise an error or return a specific value (e.g., `None` or an error message).
2. **Base Cases**:
   - If `n == 1` or `n == 2`, return `1`.
3. **Recursive Case**: 
   - Calculate `fib(n-1)` and `fib(n-2)`.
   - Return the sum of `fib(n-1)` and `fib(n-2)`.

Edge Cases:
- Handle `n < 1` by raising an error or returning a specific value.
- Ensure the function does not exceed the limit of `n = 50` to avoid excessive computation.

Complexity:
- Time Complexity: O(2^n) due to the exponential nature of the recursive calls.
- Space Complexity: O(n) due to the recursion stack.

This algorithm ensures the function behaves as specified, handling edge cases and providing the correct Fibonacci number for valid inputs.
