Requirements:
- The function `correct_bracketing` takes a single input `brackets` (a string).
- The input string contains only the characters "<" and ">".
- The function returns `True` if every opening bracket "<" has a corresponding closing bracket ">".
- The function returns `False` otherwise.
- Edge cases:
  - An empty string should return `False`.
  - A string with only opening brackets (e.g., "<") should return `False`.
  - A string with only closing brackets (e.g., ">") should return `False`.
  - A string with mismatched brackets (e.g., "><<>") should return `False`.
