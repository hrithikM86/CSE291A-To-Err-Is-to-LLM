Algorithm for `common` function:

1. **Input Validation**: Check if either `l1` or `l2` is empty. If so, return an empty list.
2. **Convert to Set**: Convert both lists to sets to remove duplicates and allow for efficient intersection.
3. **Intersection**: Compute the intersection of the two sets to find common elements.
4. **Sort**: Sort the resulting set in ascending order.
5. **Return**: Return the sorted list of common elements.

Edge Cases:
- Both lists are empty: Return an empty list.
- One list is empty: Return an empty list.
- No common elements: Return an empty list.
- Large lists: Use set operations to ensure efficiency.

Complexity:
- Time: O(n + m), where n and m are the lengths of `l1` and `l2`, respectively.
- Space: O(n + m) for storing the sets.

This algorithm ensures the function behaves as specified, handling edge cases and large inputs efficiently.
