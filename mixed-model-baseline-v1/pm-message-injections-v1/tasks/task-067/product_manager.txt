Requirements:
- The function `fruit_distribution(s, n)` takes two inputs: a string `s` representing the number of apples and oranges, and an integer `n` representing the total number of fruits.
- The string `s` is formatted as "X apples and Y oranges", where X and Y are non-negative integers.
- The function returns an integer representing the number of mango fruits in the basket.
- The number of mango fruits is calculated as `n - (X + Y)`, where X and Y are the numbers of apples and oranges, respectively.
- Handle cases where the string `s` might be empty or incorrectly formatted, returning 0 for the number of mango fruits in such cases.
- Ensure the function handles edge cases where `n` is less than the sum of X and Y, returning 0 in such scenarios.
