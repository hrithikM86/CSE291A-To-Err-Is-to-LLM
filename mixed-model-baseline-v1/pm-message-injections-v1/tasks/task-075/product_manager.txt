Requirements:
- Function: `is_multiply_prime(a)`
- Input: `a` (an integer, where 0 < a < 100)
- Output: Boolean value (`True` if `a` is the product of 3 prime numbers, `False` otherwise)
- Behavior: Check if `a` can be expressed as the product of exactly 3 prime numbers.
- Edge Cases:
  - `a` = 2, 3, 5 (prime numbers themselves) -> `False`
  - `a` = 30 (2 * 3 * 5) -> `True`
  - `a` = 60 (2 * 2 * 3 * 5) -> `False`
  - `a` = 1 (not a product of primes) -> `False`
  - `a` = 99 (3 * 3 * 11) -> `True`
