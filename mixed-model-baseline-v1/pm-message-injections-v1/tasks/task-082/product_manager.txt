Requirements:
- **Input**: A single string `string`.
- **Output**: A boolean value (`True` or `False`).
- **Behavior**:
  - Return `True` if the length of the string is a prime number.
  - Return `False` if the length of the string is not a prime number.
- **Examples**:
  - `prime_length('Hello')` should return `True`.
  - `prime_length('abcdcba')` should return `True`.
  - `prime_length('kittens')` should return `True`.
  - `prime_length('orange')` should return `False`.
- **Edge Cases**:
  - An empty string should return `False` (length 0 is not a prime number).
  - Single-character strings should return `True` (length 1 is not considered prime, but the function should handle it correctly).
