Requirements:
- Input: N (an integer, 0 ≤ N ≤ 10000)
- Output: A string representing the binary form of the sum of the digits of N
- Behavior: 
  - Convert N to its decimal digit sum
  - Convert the resulting sum to binary
  - Return the binary string
- Edge Cases:
  - N = 0: Output should be "0"
  - N = 10000: Output should be "11111101000" (sum of digits is 16)
