Algorithm for `add(lst)`:

1. **Input Validation**: Check if the list `lst` is non-empty. If not, raise an error.
2. **Initialization**: Set `sum_even = 0` to store the sum of even elements at odd indices.
3. **Traversal**: Iterate through the list using an index-based loop, starting from index 1 (the first odd index) and increment by 2.
4. **Condition Check**: For each element at the current index:
   - Check if the element is even.
   - If even, add it to `sum_even`.
5. **Output**: Return `sum_even`.

**Edge Cases**:
- If the list is empty, raise an error.
- If there are no even elements at odd indices, return 0.

**Complexity**:
- Time Complexity: O(n), where n is the length of the list.
- Space Complexity: O(1), as only a few variables are used.
