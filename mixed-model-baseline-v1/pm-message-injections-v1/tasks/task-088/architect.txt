Algorithm for `sort_array(array)`:

1. **Input Validation**: Check if the input array is empty. If so, return an empty array.
2. **Edge Case Handling**:
   - If the array has only one element, return the array as is.
3. **Determine Sorting Order**:
   - Calculate the sum of the first and last elements of the array.
   - If the sum is odd, sort the array in ascending order.
   - If the sum is even, sort the array in descending order.
4. **Return the Sorted Array**: Return a new list that is a sorted copy of the original array.

Complexity:
- **Time Complexity**: O(n log n) due to the sorting operation.
- **Space Complexity**: O(n) for storing the sorted array.

This algorithm ensures that the original array is not modified and handles all specified edge cases.
