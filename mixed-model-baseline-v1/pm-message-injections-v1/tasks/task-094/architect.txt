Algorithm:

1. Define a helper function `is_prime(n)` to check if a number is prime.
2. Initialize `max_prime` to -1.
3. Iterate through each number `num` in `lst`:
   - If `num` is positive and an integer:
     - Use `is_prime(num)` to check if `num` is prime.
     - If `num` is prime and greater than `max_prime`, update `max_prime` to `num`.
4. If `max_prime` is -1, return 0 (no prime numbers found).
5. Otherwise, sum the digits of `max_prime` and return the sum.

Edge Cases:
- Handle empty list: `max_prime` remains -1, return 0.
- Handle list with no prime numbers: `max_prime` remains -1, return 0.
- Handle list with negative numbers: Ignore them in the prime check.
- Handle non-integer values: Ignore them in the iteration.

Complexity:
- Time: O(n * sqrt(max_num)), where n is the length of `lst` and max_num is the largest number in `lst`.
- Space: O(1) for the helper function and variables.
