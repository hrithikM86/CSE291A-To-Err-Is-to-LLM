   - **Step 3:** For each index `i`:
     - Check if `s[i]` is an uppercase vowel ('A', 'E', 'I', 'O', 'U').

5. **Example Implementations:**
   ```python
   def count_upper(s: str) -> int:
       count = 0
       vowels = {'A', 'E', 'I', 'O', 'U'}
       
       for i in range(0, len(s), 2):
           if s[i] in vowels:
               count += 1
       
       return count
   ```
