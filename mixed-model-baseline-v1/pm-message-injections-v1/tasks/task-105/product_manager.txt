Requirements:
- **Inputs**: A list of integers (`arr`).
- **Outputs**: A list of strings.
- **Behavior**:
  - Sort the integers in `arr` that are between 1 and 9 inclusive.
  - Reverse the sorted list.
  - Replace each digit with its corresponding name: "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine".
- **Edge Cases**:
  - If `arr` is empty, return an empty list.
  - If `arr` contains numbers outside the range 1-9, ignore them.
  - If `arr` contains only numbers outside the range 1-9, return a list with the corresponding name of the smallest number (if any).
