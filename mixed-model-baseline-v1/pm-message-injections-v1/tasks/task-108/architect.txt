Algorithm for `count_nums(arr)`:

1. **Input Validation**: Check if `arr` is empty. If so, return 0.
2. **Initialization**: Set a counter `count` to 0.
3. **Iterate through each element** in `arr`:
   - **Handle Negative Numbers**: If the number is negative, split it into its digits, considering the first digit as negative.
   - **Handle Positive and Zero Numbers**: For positive numbers and zero, split into digits normally.
   - **Sum of Digits**: Calculate the sum of these digits.
   - **Check Condition**: If the sum of digits is greater than 0, increment the counter `count`.
4. **Return the Counter**: After iterating through all elements, return the value of `count`.

**Edge Cases**:
- Empty list: Return 0.
- List with only negative single-digit numbers: Return 0.
- Mixed list: Correctly count elements based on the sum of their digits.

**Complexity**:
- Time: O(n * d), where n is the number of elements in `arr` and d is the number of digits in the largest number.
- Space: O(1) additional space, excluding the input and output.
