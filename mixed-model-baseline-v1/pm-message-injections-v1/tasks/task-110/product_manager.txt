Requirements:
- The function `exchange(lst1, lst2)` should take two lists of integers as input.
- It should return a string: "YES" if it's possible to exchange elements between the lists to make `lst1` contain only even numbers, otherwise "NO".
- No limit on the number of exchanged elements.
- Both input lists are non-empty.
- Edge cases:
  - If `lst1` already contains only even numbers, return "YES".
  - If `lst2` contains only odd numbers, return "NO" if `lst1` cannot be made even with exchanges.
  - If both lists are empty, return "NO" (though this case is not applicable as per the assumption).
