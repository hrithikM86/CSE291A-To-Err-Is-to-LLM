Requirements:
- Function: `reverse_delete(s, c)`
- Inputs:
  - `s`: A string (1 <= len(s) <= 1000)
  - `c`: A string containing characters to be deleted from `s`
- Output:
  - A tuple containing:
    - A new string with all characters from `c` removed from `s`
    - A boolean indicating if the resulting string is a palindrome
- Behavior:
  - Remove all characters in `s` that are present in `c`
  - Check if the resulting string is a palindrome
  - Return a tuple with the cleaned string and the palindrome check result
- Edge Cases:
  - `s` or `c` is empty: Return `('', False)`
  - `s` contains no characters from `c`: Return `(s, s == s[::-1])`
  - `s` is already a palindrome: Return `(s, True)`
