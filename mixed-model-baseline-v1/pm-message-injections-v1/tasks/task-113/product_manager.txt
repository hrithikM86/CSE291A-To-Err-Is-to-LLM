Requirements:
- **Inputs**: A list of strings, where each string contains only digits.
- **Outputs**: A list of strings. Each output string should describe the number of odd digits in the corresponding input string.
- **Behavior**:
  - For each input string, count the number of odd digits.
  - Replace the word "number" with the count of odd digits.
  - Replace the word "string" with the count of odd digits.
  - Replace the word "input" with the count of odd digits.
- **Edge Cases**:
  - If an input string is empty, return an empty string in the output.
  - If an input string contains no odd digits, ensure the output string correctly reflects this.
