Requirements:
- **Inputs**: A single string `word` consisting of English letters.
- **Outputs**: A single character string representing the closest vowel between two consonants from the right, or an empty string if no such vowel exists.
- **Behavior**:
  - Search for vowels from right to left.
  - A vowel is valid if it is between two consonants.
  - Vowels at the beginning or end of the word are not considered.
- **Edge Cases**:
  - Empty string input: Return an empty string.
  - Single character input: Return an empty string.
  - No valid vowels: Return an empty string.
  - Vowels at the beginning or end: Return an empty string.
