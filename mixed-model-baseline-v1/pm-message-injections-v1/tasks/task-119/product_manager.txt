Requirements:
- The function `match_parens(lst)` takes a single input `lst`, which is a list of two strings consisting only of '(' and ')'.
- The function returns a string: 'Yes' if the two strings can be concatenated in some order to form a balanced parentheses string, and 'No' otherwise.
- A string is balanced if every '(' has a corresponding ')' and they are properly nested.
- Consider edge cases where the input list contains empty strings or strings with only one type of parenthesis.
- Ensure the function handles cases where the strings cannot be concatenated to form a balanced string.
