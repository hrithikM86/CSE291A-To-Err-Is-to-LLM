Requirements:
- **Input**: A positive integer `n`.
- **Output**: A sorted list of integers containing only the odd numbers from the Collatz sequence starting with `n`.
- **Behavior**:
  - The Collatz sequence is generated by repeatedly applying the following rules:
    - If the current term is even, divide it by 2.
    - If the current term is odd, multiply it by 3 and add 1.
  - The sequence ends when it reaches 1.
  - The output list should contain only the odd numbers from this sequence, sorted in increasing order.
- **Edge Cases**:
  - If `n` is 1, the output should be `[1]`.
  - If `n` is even, the first odd number in the sequence will be `n` itself, if it is odd.
  - If the sequence does not contain any odd numbers (which is not possible given the rules), the output should be an empty list.
