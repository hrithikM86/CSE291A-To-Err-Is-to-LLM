Algorithm:

1. Check if the input string is empty. If yes, return False.
2. Split the string by '-' to get month, day, and year.
3. Convert month, day, and year to integers.
4. Check if month is between 1 and 12. If not, return False.
5. Check if day is within the valid range for the month:
   - 1-31 for months 1, 3, 5, 7, 8, 10, 12.
   - 1-30 for months 4, 6, 9, 11.
   - 1-29 for month 2.
   If not, return False.
6. For month 2, check if the year is a leap year and adjust the day range to 1-29 if not.
7. If all checks pass, return True.

Complexity:
- Time: O(1) as the operations are constant regardless of input size.
- Space: O(1) as no additional space is used.
