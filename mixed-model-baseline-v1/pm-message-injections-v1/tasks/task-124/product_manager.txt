Requirements:
- Input: A string representing a date in the format 'mm-dd-yyyy'.
- Output: A boolean value indicating whether the date is valid (True) or not (False).
- The date is valid if:
  1. The string is not empty.
  2. The month (mm) is between 1 and 12.
  3. The day (dd) is within the valid range for the month:
     - 1-31 for months 1, 3, 5, 7, 8, 10, 12.
     - 1-30 for months 4, 6, 9, 11.
     - 1-29 for month 2.
  4. The year (yyyy) is a four-digit number.
- Edge cases:
  - Empty string input.
  - Invalid date format.
  - Month out of range.
  - Day out of range for the given month.
