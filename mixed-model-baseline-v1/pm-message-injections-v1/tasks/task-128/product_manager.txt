Requirements:
- **Inputs**: A list of integers (`arr`).
- **Outputs**: An integer representing the sum of magnitudes of integers multiplied by the product of signs, or `None` if the array is empty.
- **Behavior**:
  - For each integer in the array, multiply its magnitude by the product of its sign (1, -1, or 0).
  - Sum these products.
- **Edge Cases**:
  - Return `None` if the input array is empty.
  - Handle negative numbers correctly (sign = -1), positive numbers (sign = 1), and zeros (sign = 0).
