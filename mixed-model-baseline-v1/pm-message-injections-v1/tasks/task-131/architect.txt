Algorithm:

1. **Input Validation**: Ensure `n` is a positive integer.
2. **Edge Case Handling**:
   - If `n` is 0, return 0.
   - If `n` is a single digit, check if it's odd or even:
     - Return `n` if odd.
     - Return 0 if even.
3. **Digit Extraction and Product Calculation**:
   - Initialize `product` to 1.
   - While `n` is greater than 0:
     - Extract the last digit of `n`.
     - If the digit is odd, multiply it with `product`.
     - Remove the last digit from `n`.
   - If `product` remains 1, all digits were even, so return 0.
   - Otherwise, return `product`.

Complexity:
- Time: O(d), where d is the number of digits in `n`.
- Space: O(1), constant space is used.

This algorithm ensures all edge cases are handled correctly and efficiently.
