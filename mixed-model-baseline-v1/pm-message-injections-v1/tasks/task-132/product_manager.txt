Requirements:
- The function `is_nested` takes a single input `string` (a string containing only square brackets).
- The function returns `True` if there is at least one nested pair of square brackets in the string.
- The function returns `False` if there are no nested pairs or if the string is invalid (e.g., unbalanced brackets).
- Edge cases:
  - An empty string returns `False`.
  - A string with unbalanced brackets returns `False`.
  - A string with no nested brackets returns `False`.
  - A string with only one pair of brackets returns `False`.
  - A string with valid nested brackets returns `True`.
