Algorithm for `sum_squares(lst)`:

1. Initialize `total_sum` to 0.
2. Iterate over each index `i` and value `val` in the list `lst`:
   - If `i % 3 == 0`, square `val` and add the result to `total_sum`.
   - If `i % 4 == 0` and `i % 3 != 0`, cube `val` and add the result to `total_sum`.
   - Otherwise, add `val` to `total_sum` as is.
3. Return `total_sum`.

Edge Cases:
- Handle empty list: Return 0.
- Ignore non-integer values: Treat them as non-modified.
- Negative indices: Not expected, but if present, treat them as non-modified.

Complexity:
- Time: O(n), where n is the length of the list.
- Space: O(1), as no additional space is used other than the input list and a few variables.
