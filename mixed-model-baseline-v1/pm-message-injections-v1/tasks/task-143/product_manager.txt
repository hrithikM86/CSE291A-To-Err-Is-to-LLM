Requirements:
- **Inputs**: A string `sentence` containing words separated by spaces.
- **Outputs**: A string containing words from the original sentence whose lengths are prime numbers, preserving the original order.
- **Behavior**:
  - Split the sentence into words.
  - Check the length of each word to determine if it is a prime number.
  - Collect and join the words with prime length into a new string.
- **Edge Cases**:
  - Empty string input: Return an empty string.
  - Sentence with no words of prime length: Return an empty string.
  - Sentence with only one word: Return the word if its length is prime, otherwise return an empty string.
  - Sentence with words of non-prime lengths only: Return an empty string.
