Requirements:
- The function `bf` takes two string parameters, `planet1` and `planet2`.
- It returns a tuple of planet names that are located between the orbits of `planet1` and `planet2`, sorted by proximity to the Sun.
- If either `planet1` or `planet2` is not a valid planet name, return an empty tuple.
- Valid planet names are: "Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune".
- Examples:
  - `bf("Jupiter", "Neptune")` returns `("Saturn", "Uranus")`.
  - `bf("Earth", "Mercury")` returns `("Venus")`.
  - `bf("Mercury", "Uranus")` returns `("Venus", "Earth", "Mars", "Jupiter", "Saturn")`.
