Requirements:
- **Inputs**: A list of numbers (`lst`).
- **Outputs**: An integer representing the sum of squares of the odd, non-negative, and non-negative integer numbers in the list.
- **Behavior**:
  - Square each odd, non-negative, and non-negative integer number in the list.
  - Sum these squares.
  - Return the sum.
- **Edge Cases**:
  - If the list contains no valid numbers (non-negative, non-negative integers, and odd), return 0.
  - If the input list is empty, return 0.
