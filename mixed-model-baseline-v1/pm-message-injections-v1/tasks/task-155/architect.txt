Algorithm:

1. Define the function `even_odd_count(num)`.

2. Handle edge cases:
   - If `num` is `0`, return `(1, 0)`.
   - If `num` is negative, convert `num` to a string and check if the first character is a minus sign. If so, initialize even and odd counts to 1 and 0 respectively.

3. Convert `num` to a string to easily iterate over each digit.

4. Initialize two counters: `even_count` and `odd_count` to 0.

5. Iterate over each character in the string:
   - If the character is '0' to '9':
     - Convert the character to an integer.
     - If the integer is even, increment `even_count`.
     - If the integer is odd, increment `odd_count`.
   - If the character is a minus sign and `num` is negative, continue to the next iteration.

6. Return a tuple `(even_count, odd_count)`.

Complexity:
- Time: O(d), where d is the number of digits in `num`.
- Space: O(1), as only a few variables are used.

This algorithm efficiently handles the given requirements and edge cases.
