Requirements:
- **Input**: A single string `text`.
- **Output**: A string representing the MD5 hash of `text`, or `None` if `text` is an empty string.
- **Behavior**:
  - Compute the MD5 hash of the input string.
  - Return the hash as a hexadecimal string.
  - Return `None` if the input string is empty.
- **Edge Cases**:
  - An empty string input should return `None`.
  - Non-string inputs should not be handled; ensure the input is always a string.
