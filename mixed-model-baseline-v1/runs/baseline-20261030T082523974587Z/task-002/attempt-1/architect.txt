Algorithm:

1. **Input Validation**: Ensure the input is a valid float.
2. **Negative Number Handling**: 
   - If `number` is negative, return `number - int(number)`.
3. **Integer Handling**: 
   - If `number` is an integer (no decimal part), return `0.0`.
4. **General Case**:
   - For any other positive float, return `number - int(number)`.

Complexity:
- Time Complexity: O(1) - The operations are constant time.
- Space Complexity: O(1) - No additional space is used.

Edge Cases:
- `number = -3.5` should return `-0.5`.
- `number = 4.0` should return `0.0`.
- `number = 0.0` should return `0.0`.

This algorithm covers all specified edge cases and the general behavior as required.
