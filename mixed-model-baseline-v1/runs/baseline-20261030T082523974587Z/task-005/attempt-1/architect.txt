Algorithm:

1. Initialize an empty list `result` to store the final output.
2. If `numbers` is empty, return `result` (an empty list).
3. Iterate through each element `num` in `numbers`:
   - Append `num` to `result`.
   - If `num` is not the last element in `numbers`, append `delimiter` to `result`.
4. Return `result`.

Edge Cases:
- Handling an empty `numbers` list.
- `delimiter` can be any integer value.

Complexity:
- Time: O(n), where n is the length of `numbers`.
- Space: O(n), for storing the result list.
