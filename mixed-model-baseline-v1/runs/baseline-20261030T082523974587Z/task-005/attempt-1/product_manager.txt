Requirements:
- **Inputs**: 
  - `numbers`: A list of integers.
  - `delimiter`: An integer to be inserted between elements of `numbers`.
- **Outputs**: 
  - A list of integers where `delimiter` is inserted between every two consecutive elements of `numbers`.
- **Behavior**:
  - If `numbers` is empty, return an empty list.
  - Insert `delimiter` between each pair of consecutive elements in `numbers`.
- **Edge Cases**:
  - An empty `numbers` list should return an empty list.
  - `delimiter` can be any integer value.
