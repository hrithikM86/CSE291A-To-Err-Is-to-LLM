Requirements:
- The function `parse_nested_parens` takes a single input `paren_string` (type: str).
- The input string contains multiple groups of nested parentheses separated by spaces.
- For each group, the function should return the maximum depth of nesting.
- The output is a list of integers, where each integer represents the maximum nesting depth for each group.
- Edge cases:
  - Empty string input should return an empty list.
  - Groups with no parentheses should return 0.
  - Groups with unbalanced parentheses should raise a ValueError.
- The function should correctly handle nested parentheses within each group.
