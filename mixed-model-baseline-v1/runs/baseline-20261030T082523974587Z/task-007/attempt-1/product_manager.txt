Requirements:
- **Inputs**: 
  - `strings`: A list of strings.
  - `substring`: A string to filter the list by.
- **Outputs**: 
  - A list of strings that contain the given `substring`.
- **Behavior**:
  - Return an empty list if `strings` is empty.
  - Include strings in the output list if they contain the `substring`, regardless of case.
- **Edge Cases**:
  - Empty `strings` list: Return an empty list.
  - `substring` is an empty string: Return the original `strings` list.
  - No strings contain the `substring`: Return an empty list.
