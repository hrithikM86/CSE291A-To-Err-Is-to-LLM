Algorithm:

1. Initialize `sum` to 0 and `product` to 1.
2. Iterate through each number in the `numbers` list:
   - Add the current number to `sum`.
   - Multiply the current number with `product`. If the current number is 0, set `product` to 0 immediately.
3. After the loop, return a tuple `(sum, product)`.
4. Handle edge cases:
   - If the list is empty, return `(0, 1)` directly.

Complexity:
- Time: O(n), where n is the length of the `numbers` list.
- Space: O(1), constant space is used.

This algorithm ensures that the sum is correctly calculated as 0 for an empty list and the product is 1, with the product being 0 if any number in the list is 0.
