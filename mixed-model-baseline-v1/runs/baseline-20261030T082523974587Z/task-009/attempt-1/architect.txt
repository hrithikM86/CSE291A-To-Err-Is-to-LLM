Algorithm:

1. Initialize an empty list `rolling_max_values` to store the rolling maximum values.
2. If the input list `numbers` is empty, return `rolling_max_values`.
3. Initialize `current_max` to negative infinity.
4. Iterate through each number in `numbers`:
   - Update `current_max` to be the maximum of `current_max` and the current number.
   - Append `current_max` to `rolling_max_values`.
5. Return `rolling_max_values`.

Complexity:
- Time Complexity: O(n), where n is the length of the input list `numbers`.
- Space Complexity: O(n), for storing the rolling maximum values.

Edge Cases:
- An empty input list should return an empty list.
- A list with a single element should return a list containing that single element.
- The algorithm handles negative numbers correctly by initializing `current_max` to negative infinity.
