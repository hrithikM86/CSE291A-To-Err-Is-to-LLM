Requirements:
- The function `string_xor` takes two inputs, `a` and `b`, both of which are strings consisting only of '0's and '1's.
- The function should perform a binary XOR operation on the two input strings.
- The result of the XOR operation should be returned as a string.
- The input strings `a` and `b` can have different lengths.
- If the input strings are not binary strings (i.e., contain characters other than '0' and '1'), the function should raise a `ValueError`.
- Edge cases:
  - If either `a` or `b` is an empty string, return an empty string.
  - If the input strings contain characters other than '0' and '1', raise a `ValueError`.
