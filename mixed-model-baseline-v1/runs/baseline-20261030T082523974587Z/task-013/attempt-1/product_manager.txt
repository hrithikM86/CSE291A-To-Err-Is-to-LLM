Requirements:
- The function `greatest_common_divisor` takes two integer inputs `a` and `b`.
- It returns an integer representing the greatest common divisor (GCD) of `a` and `b`.
- Handle both positive and negative integers.
- Edge cases:
  - If either `a` or `b` is 0, return the non-zero value (as per mathematical convention).
  - If both `a` and `b` are 0, return 0 (undefined, but this is a common convention).
- Use appropriate algorithms like Euclidean algorithm for computation.
