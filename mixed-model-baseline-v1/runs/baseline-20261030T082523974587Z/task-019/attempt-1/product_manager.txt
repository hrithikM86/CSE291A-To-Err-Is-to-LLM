Requirements:
- Input: A string of space-delimited number words ('zero' to 'nine').
- Output: A string with the number words sorted from smallest to largest.
- Behavior: Convert the number words to their numerical values, sort them, and then convert back to number words.
- Edge Cases:
  - Empty string input: Return an empty string.
  - Input with invalid number words: Ignore invalid words and sort only valid ones.
  - Single word input: Return the word as is.
