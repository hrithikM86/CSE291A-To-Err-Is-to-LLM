Requirements:
- **Inputs**: A list of floating-point numbers (`numbers: List[float]`).
- **Outputs**: A tuple containing two floating-point numbers that are the closest to each other (`Tuple[float, float]`).
- **Behavior**: 
  - The function should return the two closest numbers in ascending order.
  - If there are multiple pairs with the same smallest difference, return any one pair.
- **Edge Cases**:
  - The input list will have at least two elements.
  - All elements in the list will be unique (though this can be relaxed if the specification allows for ties).
  - The list may contain negative numbers and/or non-integer values.
