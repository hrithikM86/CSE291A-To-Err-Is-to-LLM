Requirements:
- The function `factorize` takes an integer `n` as input.
- It returns a list of prime factors of `n` in ascending order.
- Each prime factor appears in the list as many times as it divides `n`.
- The product of the returned factors equals the input number `n`.
- Handle edge cases such as `n` being 0 or 1, where the function should return an empty list or `[n]` respectively.
- Ensure the input `n` is a positive integer.
