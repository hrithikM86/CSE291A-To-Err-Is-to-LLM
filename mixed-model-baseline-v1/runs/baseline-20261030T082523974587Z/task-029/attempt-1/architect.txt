Algorithm:

1. Define the function `filter_by_prefix(strings: List[str], prefix: str) -> List[str]`.
2. Initialize an empty list `filtered_strings` to store the results.
3. Iterate through each string `s` in `strings`:
   - Check if `s` starts with `prefix` using `s.startswith(prefix)`.
   - If true, append `s` to `filtered_strings`.
4. Return `filtered_strings`.

Edge Cases:
- If `strings` is empty, return an empty list.
- If `prefix` is an empty string, return the original `strings` list.
- Handle strings of varying lengths, ensuring only those starting exactly with `prefix` are included.

Complexity:
- Time: O(n * m), where n is the number of strings and m is the average length of the strings.
- Space: O(k), where k is the number of strings starting with the prefix.
