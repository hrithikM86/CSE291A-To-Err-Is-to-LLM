Requirements:
- Input: A list `l` of integers.
- Output: A list containing only the positive integers from the input list, in the same order they appeared.
- Behavior: The function should iterate through the list and collect all positive numbers.
- Edge Cases:
  - An empty list returns an empty list.
  - A list with no positive numbers returns an empty list.
  - A list with all positive numbers returns the same list.
