Requirements:
- Input: A single list `l` of integers.
- Output: A sorted list of unique integers from the input list.
- Behavior: The function should remove duplicate elements from the input list and return a sorted list of the remaining unique elements.
- Edge Cases:
  - Empty list: Return an empty list.
  - List with all duplicates: Return a list with a single instance of each element.
  - List with no duplicates: Return the same list, but sorted.
