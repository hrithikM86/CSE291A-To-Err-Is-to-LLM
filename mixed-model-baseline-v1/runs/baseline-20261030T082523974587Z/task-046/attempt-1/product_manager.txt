Requirements:
- Implement the `fib4` function that takes an integer `n` as input.
- Compute the n-th element of the Fib4 number sequence without using recursion.
- The sequence is defined as follows:
  - `fib4(0) -> 0`
  - `fib4(1) -> 0`
  - `fib4(2) -> 2`
  - `fib4(3) -> 0`
  - `fib4(n) -> fib4(n-1) + fib4(n-2) + fib4(n-3) + fib4(n-4)` for `n > 3`.
- Expected outputs:
  - `fib4(5) -> 4`
  - `fib4(6) -> 8`
  - `fib4(7) -> 14`
- Handle edge cases, such as negative inputs, by raising a `ValueError`.
- Use an iterative approach to ensure efficiency.
