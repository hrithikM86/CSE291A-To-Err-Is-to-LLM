Algorithm for `modp(n: int, p: int)`:

1. **Base Case**: If `n == 0`, return `1` (since \(2^0 \mod p = 1\)).
2. **Edge Case**: If `p == 1`, return `0` if `n > 0`, otherwise return `1`.
3. **Recursive Calculation**:
   - Use the property \(2^n \mod p = (2^{n/2} \mod p)^2 \mod p\) for even `n`.
   - Use the property \(2^n \mod p = (2^{(n-1)/2} \mod p)^2 \cdot 2 \mod p\) for odd `n`.
4. **Handling Large `n`**:
   - Use an iterative approach to avoid stack overflow and numeric overflow.
   - Initialize `result = 1`.
   - For each bit in the binary representation of `n`:
     - Square `result` and take modulo `p`.
     - If the current bit is set, multiply `result` by `2` and take modulo `p`.
5. **Complexity**:
   - Time complexity: \(O(\log n)\) due to the logarithmic number of multiplications.
   - Space complexity: \(O(1)\) as no additional space is used other than variables.

This algorithm ensures efficient computation and handles edge cases as specified.
