Requirements:
- Implement the `modp` function that takes two integers `n` and `p`.
- Return the result of \(2^n \mod p\).
- Handle large values of `n` to avoid numeric overflow.
- Test cases include:
  - `modp(3, 5)` should return `3`.
  - `modp(1101, 101)` should return `2`.
  - `modp(0, 101)` should return `1`.
  - `modp(3, 11)` should return `8`.
  - `modp(100, 101)` should return `1`.

Edge cases:
- Ensure the function works correctly for `n` close to the maximum integer value.
- Verify the function handles `p` as `1` (result should be `0` for any `n` except `0`).
