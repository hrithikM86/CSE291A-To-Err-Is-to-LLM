Requirements for the `fib` function:

- **Input**: A single integer `n` (1 ≤ n ≤ 50).
- **Output**: The n-th Fibonacci number.
- **Behavior**:
  - The function should return the correct Fibonacci number for the given `n`.
  - The Fibonacci sequence starts with 0 and 1.
- **Edge Cases**:
  - `n = 1` should return `1`.
  - `n = 2` should return `1`.
  - `n = 50` should not result in an infinite loop or excessive computation time.
  - `n < 1` should not be a valid input; the function should handle this appropriately (e.g., by raising an error or returning a specific value).
