Requirements:
- Function: `common`
- Inputs: Two lists, `l1` and `l2`, containing integers.
- Output: A sorted list of unique integers that are common to both input lists.
- Behavior:
  - Return a list of common elements, sorted in ascending order.
  - Ensure all elements in the output list are unique.
- Edge Cases:
  - If no common elements, return an empty list.
  - If one or both lists are empty, return an empty list.
  - Handle large lists efficiently.
