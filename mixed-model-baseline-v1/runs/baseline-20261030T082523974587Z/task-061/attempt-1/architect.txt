Algorithm:

1. Initialize a counter `open_brackets` to 0.
2. Iterate through each character `c` in the string `brackets`:
   - If `c` is '(', increment `open_brackets`.
   - If `c` is ')', decrement `open_brackets`.
   - If `open_brackets` is negative at any point, return `False`.
3. After the loop, return `True` if `open_brackets` is 0, otherwise return `False`.

Edge Cases:
- Empty string: Return `True`.
- Unmatched opening or closing brackets: Return `False`.
- Only opening or closing brackets: Return `False` for all but empty string.

Complexity:
- Time: O(n), where n is the length of the string.
- Space: O(1), constant space used.
