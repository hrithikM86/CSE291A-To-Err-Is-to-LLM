Algorithm for `fruit_distribution(s, n)`:

1. **Input Validation**:
   - Check if `s` is empty or not in the format "X apples and Y oranges".
   - If `s` is invalid, return 0.

2. **Extract Numbers**:
   - Use regular expressions to extract `X` and `Y` from `s`.
   - Convert `X` and `Y` to integers.

3. **Calculate Mango Fruits**:
   - If `n` is less than the sum of `X` and `Y`, return 0.
   - Otherwise, return `n - (X + Y)`.

4. **Edge Cases**:
   - If `s` is empty, return 0.
   - If `s` does not contain "apples and oranges", return 0.
   - If `X` or `Y` cannot be converted to integers, return 0.

5. **Return Result**:
   - Return the calculated number of mango fruits.

Complexity:
- **Time Complexity**: O(1) - The operations are constant time.
- **Space Complexity**: O(1) - No additional space is used other than variables for the result and temporary storage.

This algorithm ensures that all edge cases are handled as per the requirements.
