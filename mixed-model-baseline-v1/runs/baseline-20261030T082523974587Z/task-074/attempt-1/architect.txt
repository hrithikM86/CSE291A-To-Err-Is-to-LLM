Algorithm for `total_match(lst1, lst2)`:

1. Calculate the total number of characters in `lst1` and `lst2`.
2. Compare the total character counts:
   - If `lst1` has fewer characters, return `lst1`.
   - If `lst2` has fewer characters, return `lst2`.
   - If both have the same number of characters, return `lst1`.
3. Handle edge cases:
   - If either list is empty, return the non-empty list or an empty list if both are empty.

Complexity:
- Time: O(n + m), where n and m are the lengths of `lst1` and `lst2`, respectively.
- Space: O(1), as no additional space is used other than variables for counting characters.

This algorithm ensures the function behaves as specified, including handling edge cases where lists are empty or have the same total character count.
