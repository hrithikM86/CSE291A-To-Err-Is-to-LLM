Requirements:
- The function `total_match` takes two lists of strings (`lst1`, `lst2`) as input.
- It returns the list with the total number of characters in all strings less than the other list.
- If both lists have the same total number of characters, return the first list.
- Handle edge cases where lists are empty.
- Examples:
  - `total_match([], [])` returns `[]`
  - `total_match(['hi', 'admin'], ['hI', 'Hi'])` returns `['hI', 'Hi']`
  - `total_match(['hi', 'admin'], ['hi', 'hi', 'admin', 'project'])` returns `['hi', 'admin']`
  - `total_match(['hi', 'admin'], ['hI', 'hi', 'hi'])` returns `['hI', 'hi', 'hi']`
  - `total_match(['4'], ['1', '2', '3', '4', '5'])` returns `['4']`
