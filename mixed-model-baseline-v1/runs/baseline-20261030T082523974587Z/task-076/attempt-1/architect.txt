Algorithm for `is_simple_power(x, n)`:

1. **Handle edge cases:**
   - If `x` or `n` is `0`, return `False`.
   - If `n` is `1`, return `True` only if `x` is `1`.
   - If `x` is `1` and `n` is greater than `1`, return `False`.
   - If `x` is `0` and `n` is `1`, return `False`.

2. **Check if `x` is a simple power of `n`:**
   - Initialize `k` to `1`.
   - While `n**k` is less than `x`, increment `k`.
   - If `n**k` equals `x`, return `True`.
   - If `n**k` is greater than `x`, return `False`.

3. **Return the result.**

Complexity:
- The loop will run at most `log(x)` times, making the time complexity `O(log(x))`.
- The space complexity is `O(1)` as no additional space is used other than a few variables.
