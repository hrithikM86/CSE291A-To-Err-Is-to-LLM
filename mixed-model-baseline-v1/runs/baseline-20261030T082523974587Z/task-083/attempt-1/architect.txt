Algorithm for `starts_one_ends(n)`:

1. **Input Validation**:
   - Check if `n` is less than 1. If true, return an error message or raise an exception.

   - If `n` is 1, return 1 (only the number 1 itself).

   - Calculate the number of n-digit numbers starting with 1: `10^(n-1)`.
   - Calculate the number of n-digit numbers ending with 1: `10^(n-1)`.
   - Subtract the overlap (numbers starting and ending with 1): `10^(n-2)`.

4. **Return the Result**.

- Handle `n < 1` as specified (e.g., return an error message or raise an exception).
