Requirements:
- The function `get_row` takes two inputs: `lst` (a 2D list) and `x` (an integer).
- It returns a list of tuples, where each tuple represents the coordinates (row, column) of `x` in `lst`.
- The coordinates should be sorted by rows in ascending order.
- For rows with multiple occurrences of `x`, sort by columns in descending order.
- If `lst` is empty or `x` is not found, return an empty list.
- Indexing starts at 0.

Examples:
- `get_row([[1,2,3,4,5,6], [1,2,3,4,1,6], [1,2,3,4,5,1]], 1)` returns `[(0, 0), (1, 4), (1, 0), (2, 5), (2, 0)]`.
- `get_row([], 1)` returns `[]`.
- `get_row([[], [1], [1, 2, 3]], 3)` returns `[(2, 2)]`.
