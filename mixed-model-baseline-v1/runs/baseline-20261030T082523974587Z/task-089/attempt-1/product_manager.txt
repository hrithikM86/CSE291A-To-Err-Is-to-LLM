Requirements:
- The function `encrypt(s)` takes a single string `s` as input.
- It returns a new string where each letter in the input string is shifted down by 4 positions in the alphabet (2 multiplied by 2).
- If the shift goes beyond 'z', it wraps around to the beginning of the alphabet.
- The function should handle both lowercase and uppercase letters, preserving the case of the original letters.
- Non-alphabetic characters should remain unchanged.
- Edge cases:
  - Empty string input should return an empty string.
  - Input string containing only non-alphabetic characters should return the same string.
