Algorithm for `next_smallest(lst)`:

1. **Check for Edge Cases**:
   - If `lst` is empty, return `None`.
   - If `lst` has fewer than 2 unique elements, return `None`.

2. **Sort the List**:
   - Sort the list in ascending order.

3. **Identify the Second Smallest Element**:
   - Iterate through the sorted list to find the second smallest unique element.

4. **Return the Result**:
   - Return the second smallest element found.
   - If no second smallest element exists, return `None`.

**Complexity Analysis**:
- **Time Complexity**: O(n log n) due to sorting.
- **Space Complexity**: O(1) if sorting is done in place, otherwise O(n) for additional space.

**Edge Cases**:
- Empty list: Return `None`.
- List with one unique element: Return `None`.
- List with all elements the same: Return `None`.

This algorithm ensures that all specified requirements and edge cases are handled correctly.
