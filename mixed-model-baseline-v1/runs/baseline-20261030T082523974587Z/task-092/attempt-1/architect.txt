Algorithm for `any_int(x, y, z)`:

1. Check if the function receives exactly three inputs. If not, return `False`.
2. Check if all inputs are integers. If any input is not an integer, return `False`.
3. Check if any one of the numbers is equal to the sum of the other two:
   - If `x == y + z`, return `True`.
   - If `y == x + z`, return `True`.
   - If `z == x + y`, return `True`.
4. If none of the above conditions are met, return `False`.

Edge Cases:
- Non-integer inputs: Return `False`.
- Fewer than three inputs: Return `False`.
- More than three inputs: Return `False`.
- Inputs are zero or negative: Valid inputs, check logic as specified.

Complexity:
- Time Complexity: O(1) since the operations are constant.
- Space Complexity: O(1) as no additional space is used.
