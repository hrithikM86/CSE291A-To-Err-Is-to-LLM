Requirements:
- Input: lst (a list of integers)
- Output: An integer representing the sum of the digits of the largest prime number in the list. If there are no prime numbers, return 0.
- Behavior: 
  - Identify the largest prime number in the list.
  - Sum the digits of this prime number.
  - Return the sum.
- Edge Cases:
  - Empty list: Return 0
  - List with no prime numbers: Return 0
  - List with negative numbers: Consider only positive integers
  - List with non-integer values: Ignore non-integer values
