Requirements:
- The function `check_dict_case` takes a single input: `dict` (a dictionary).
- The function returns a boolean value: `True` if all keys are either all in lowercase or all in uppercase, and the dictionary is not empty; otherwise, `False`.
- The function should return `False` if the dictionary is empty.
- Examples:
  - `check_dict_case({"a":"apple", "b":"banana"})` returns `True`.
  - `check_dict_case({"a":"apple", "A":"banana", "B":"banana"})` returns `False`.
  - `check_dict_case({"a":"apple", 8:"banana", "a":"apple"})` returns `False`.
  - `check_dict_case({"Name":"John", "Age":"36", "City":"Houston"})` returns `False`.
  - `check_dict_case({"STATE":"NC", "ZIP":"12345"})` returns `True`.
