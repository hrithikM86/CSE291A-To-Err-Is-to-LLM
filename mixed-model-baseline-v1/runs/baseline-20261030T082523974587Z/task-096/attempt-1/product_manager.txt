Requirements:
- The function `count_up_to(n)` should take a single input `n` (a non-negative integer) and return a list of prime numbers.
- The returned list should contain all prime numbers less than `n`.
- If `n` is 0 or 1, return an empty list.
- The function should correctly identify prime numbers and exclude `n` itself if it is not prime.
- Edge cases:
  - `n` = 0 or 1: Return `[]`.
  - `n` = 2: Return `[2]`.
  - `n` is a prime number: Include all primes less than `n`.
  - `n` is not a prime number: Include all primes less than `n`.
