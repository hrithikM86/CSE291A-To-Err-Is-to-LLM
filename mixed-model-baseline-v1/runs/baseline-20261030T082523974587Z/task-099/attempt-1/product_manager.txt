Requirements:
- The function `closest_integer` takes a single input `value` (string).
- The function returns an integer.
- If `value` is equidistant from two integers, round it away from zero.
- Examples:
  - `closest_integer("10")` returns `10`
  - `closest_integer("15.3")` returns `15`
  - `closest_integer("14.5")` returns `15`
  - `closest_integer("-14.5")` returns `-15`
- Handle cases where `value` is a valid numeric string.
- Handle edge cases where `value` is an invalid string, returning `None` or raising an appropriate error.
