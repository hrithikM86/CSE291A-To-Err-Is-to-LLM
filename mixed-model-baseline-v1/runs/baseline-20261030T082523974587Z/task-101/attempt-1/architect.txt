Algorithm for `words_string(s)`:

1. **Input Validation**: Check if the input string `s` is empty. If it is, return an empty list.
2. **Normalization**: Replace multiple consecutive commas or spaces with a single space to handle edge cases.
3. **Splitting**: Split the string `s` using spaces as delimiters.
4. **Filtering**: Iterate through the resulting list and filter out any empty strings that may result from consecutive delimiters.
5. **Return**: Return the filtered list of words.

Edge Cases:
- Handle an empty string input by returning an empty list.
- Ensure that consecutive commas or spaces are treated as a single delimiter.
- Ignore any special characters or punctuation other than commas or spaces.

Complexity:
- The time complexity is O(n), where n is the length of the input string, due to the single pass required for normalization and splitting.
- The space complexity is O(m), where m is the number of words in the input string, for storing the resulting list of words.
