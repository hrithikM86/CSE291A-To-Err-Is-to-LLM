Requirements:
- Input: A list of positive integers `x`.
- Output: A sorted list of integers from `x` that do not contain any even digits.
- Behavior: 
  - Filter out numbers containing even digits.
  - Return the remaining numbers sorted in increasing order.
- Edge Cases:
  - Empty list: Return an empty list.
  - List with only even digit numbers: Return an empty list.
  - List with non-positive integers: Treat as invalid input, handle appropriately or raise an error.
