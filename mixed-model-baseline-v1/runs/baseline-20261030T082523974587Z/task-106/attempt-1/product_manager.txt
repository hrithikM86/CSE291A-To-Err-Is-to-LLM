Requirements:
- The function `f(n)` should take an integer `n` as input.
- It should return a list of size `n`.
- For each index `i` (starting from 0):
  - If `i` is even, the value at that index should be the factorial of `i + 1`.
  - If `i` is odd, the value at that index should be the sum of numbers from 1 to `i + 1`.
- Example: `f(5)` should return `[1, 2, 6, 24, 15]`.
- Edge cases:
  - If `n` is 0 or negative, return an empty list.
