Requirements:
- The function `move_one_ball(arr)` takes a list `arr` of unique integers as input.
- It returns `True` if the array can be sorted in non-decreasing order by performing any number of right shift operations, otherwise returns `False`.
- An empty array should return `True`.
- The input array length is at least 1 and at most 1000.
- Right shift operation moves all elements one position to the right, with the last element moving to the first position.
- Consider edge cases where the array is already sorted or nearly sorted after one right shift.
