Requirements:
- **Inputs**: A list of integers (`nums`).
- **Outputs**: An integer representing the minimum sum of any non-empty sub-array of `nums`.
- **Behavior**:
  - Find the minimum sum of any contiguous sub-array within the given list.
  - Return the minimum sum as an integer.
- **Edge Cases**:
  - If the input list is empty, raise a `ValueError`.
  - If the input list contains only one element, return that element.
  - Handle negative numbers correctly to ensure the minimum sum is found.
