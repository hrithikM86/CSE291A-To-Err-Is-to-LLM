Requirements:
- Implement `max_fill(grid, capacity)`.
- `grid` is a 2D list of integers, where each row represents a well and each 1 represents a unit of water.
- `capacity` is an integer representing the bucket's capacity.
- Return the minimum number of times buckets need to be lowered to empty all wells.
- Each well must be emptied completely before moving to the next well.
- Handle edge cases where some wells might be empty.
- Ensure the number of rows and columns are within the given constraints.
- The bucket capacity is between 1 and 10 inclusive.
