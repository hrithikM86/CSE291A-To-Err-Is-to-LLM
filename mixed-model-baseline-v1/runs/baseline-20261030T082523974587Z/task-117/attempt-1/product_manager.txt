Requirements:
- The function `select_words(s, n)` takes two inputs: a string `s` and a natural number `n`.
- It returns a list of words from `s` that contain exactly `n` consonants, in the order they appear in `s`.
- If `s` is an empty string, return an empty list.
- The input string `s` contains only letters and spaces.
- Consonants are any letters that are not vowels (a, e, i, o, u).
- Examples:
  - `select_words("Mary had a little lamb", 4)` returns `[\"little\"]`
  - `select_words("Mary had a little lamb", 3)` returns `[\"Mary\", \"lamb\"]`
  - `select_words("simple white space", 2)` returns `[]`
  - `select_words("Hello world", 4)` returns `[\"world\"]`
  - `select_words("Uncle sam", 3)` returns `[\"Uncle\"]`
