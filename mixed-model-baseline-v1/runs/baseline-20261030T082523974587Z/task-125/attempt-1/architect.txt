Algorithm for `split_words(txt)`:

1. **Whitespace Check**: 
   - If the string contains any whitespace, split the string on whitespace and return the resulting list.

2. **Comma Check**: 
   - If no whitespace, check if the string contains any commas. If so, split the string on commas and return the resulting list.

3. **Odd ASCII Count**:
   - If no whitespace or commas, iterate through each character in the string.
   - For each lowercase letter, calculate its ASCII value and check if it is odd.
   - Count and return the number of such letters.

**Edge Cases**:
- Empty string: Return an empty list.
- String with only whitespace or commas: Handle as per the rules.
- String with only non-alphabetic characters: Return 0.

**Complexity**:
- Time: O(n), where n is the length of the string.
- Space: O(n) for storing the split words or the count of letters.
