Requirements:
- The function `split_words(txt)` takes a single string `txt` as input.
- The function returns a list of words split based on the following rules:
  1. If the string contains whitespace, split on whitespace.
  2. If no whitespace, and the string contains commas, split on commas.
  3. If no whitespace or commas, return the count of lowercase letters with odd ASCII values (a=0, b=1, ..., z=25).
- Examples:
  - `split_words("Hello world!")` should return `["Hello", "world!"]`.
  - `split_words("Hello,world!")` should return `["Hello", "world!"]`.
  - `split_words("abcdef")` should return `3` (since 'b', 'd', and 'f' have odd ASCII values).
