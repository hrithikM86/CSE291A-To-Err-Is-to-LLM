Requirements:
- The function `intersection` takes two tuples `interval1` and `interval2`, each representing an interval as (start, end).
- Both intervals are closed, meaning they include both start and end points.
- The start of each interval is less than or equal to its end.
- Determine if the length of the intersection of the two intervals is a prime number.
- Return "YES" if the length is a prime number, "NO" otherwise.
- If the intervals do not intersect, return "NO".
- Example inputs and outputs:
  - `intersection((1, 2), (2, 3))` -> "NO"
  - `intersection((-1, 1), (0, 4))` -> "NO"
  - `intersection((-3, -1), (-5, 5))` -> "YES"
