Algorithm for `sum_squares(lst)`:

1. **Input Validation**: Check if the input list `lst` is empty. If it is, return 0.
2. **Initialization**: Initialize a variable `total` to 0 to store the sum of squared values.
3. **Iterate through the list**:
   - For each element `num` in `lst`:
     1. **Round Up**: Use the ceiling function to round `num` to the nearest upper integer.
     2. **Square the Number**: Square the rounded number.
     3. **Add to Total**: Add the squared number to `total`.
4. **Return the Total**: After processing all elements, return `total`.

**Edge Cases**:
- **Empty List**: Return 0.
- **Negative Numbers**: Correctly round negative numbers to the nearest upper integer.
- **Non-Integer Values**: Properly round non-integer values to the nearest upper integer.

**Complexity**:
- Time Complexity: O(n), where n is the length of the list `lst`.
- Space Complexity: O(1), as only a few variables are used regardless of the input size.
