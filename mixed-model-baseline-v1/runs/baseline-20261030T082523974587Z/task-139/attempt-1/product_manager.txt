Requirements:
- The function `special_factorial(n)` takes an integer `n` as input where `n > 0`.
- It returns the special factorial of `n`, calculated as `n! * (n-1)! * (n-2)! * ... * 1!`.
- For example, `special_factorial(4)` should return `288`.
- Handle cases where `n` is a small positive integer (e.g., 1, 2, 3) and ensure the factorial is computed correctly.
- Consider edge cases such as `n = 1` (result should be `1`) and `n = 2` (result should be `2`).
