Requirements:
- **Input**: A single string representing a file name.
- **Output**: A string, either 'Yes' or 'No'.
- **Behavior**:
  - Return 'Yes' if the file name meets all the specified conditions.
  - Return 'No' otherwise.
- **Conditions**:
  1. The file name should contain no more than three digits.
  2. The file name must contain exactly one dot ('.').
  3. The substring before the dot must start with a letter (a-z or A-Z) and not be empty.
  4. The substring after the dot must be one of ['txt', 'exe', 'dll'].
- **Edge Cases**:
  - Empty string: Return 'No'.
  - No dot: Return 'No'.
  - More than one dot: Return 'No'.
  - Invalid characters before the dot: Return 'No'.
  - Invalid extension: Return 'No'.
  - More than three digits: Return 'No'.
