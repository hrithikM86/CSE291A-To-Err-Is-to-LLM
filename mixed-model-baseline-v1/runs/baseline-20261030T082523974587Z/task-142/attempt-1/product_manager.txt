Requirements:
- **Inputs**: A list of integers (`lst`).
- **Outputs**: An integer representing the sum of the modified list entries.
- **Behavior**:
  - If an entry's index is a multiple of 3, square the integer.
  - If an entry's index is a multiple of 4 but not a multiple of 3, cube the integer.
  - Leave other entries unchanged.
  - Return the sum of all entries in the modified list.
- **Edge Cases**:
  - An empty list should return 0.
  - Negative indices and non-integer values are not expected, but the function should handle them gracefully (e.g., by ignoring them or treating them as non-modified).
