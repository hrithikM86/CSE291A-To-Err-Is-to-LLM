Algorithm:

1. Define a helper function `is_prime(n)` to check if a number `n` is prime.
2. Split the input `sentence` into words.
3. Initialize an empty list `prime_length_words` to store words with prime lengths.
4. For each word in the split sentence:
   - Calculate the length of the word.
   - If the length is prime (using `is_prime`), add the word to `prime_length_words`.
5. Join the words in `prime_length_words` into a single string with spaces.
6. Return the resulting string.

Edge Cases:
- Handle an empty string input by returning an empty string.
- If no words have prime lengths, return an empty string.
- If the sentence contains only one word, check if its length is prime; return the word if so, otherwise return an empty string.

Complexity:
- Time: O(n * √m), where n is the number of words and m is the average word length.
- Space: O(n) for storing the split words.
