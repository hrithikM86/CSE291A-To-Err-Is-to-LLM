Algorithm for `order_by_points(nums)`:

1. **Input Validation**: Check if the input list `nums` is empty. If it is, return an empty list.
2. **Digit Sum Calculation**: Define a helper function `digit_sum(n)` to calculate the sum of digits of an integer `n`. Handle negative numbers by converting them to positive before summing.
3. **Pair Creation**: Create a list of tuples where each tuple contains the original index and the digit sum of each number in `nums`.
4. **Sorting**: Sort the list of tuples first by the digit sum (ascending) and then by the original index (ascending).
5. **Result Construction**: Extract the original numbers from the sorted list of tuples to form the final sorted list.

Edge Cases:
- Handle negative numbers correctly by summing their absolute values.
- Single-digit numbers are already in their simplest form.
- An empty input list should return an empty list.

Complexity:
- The digit sum calculation for each number is O(d) where d is the number of digits.
- The overall complexity is O(n * d) for the digit sum calculation and O(n log n) for sorting, where n is the number of elements in `nums`.
