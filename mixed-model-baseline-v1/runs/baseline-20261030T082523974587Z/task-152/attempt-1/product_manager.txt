Requirements:
- The function `compare` takes two inputs: `game` (a list of integers) and `guess` (a list of integers).
- Both lists are of equal length, representing scores and guesses for a series of matches.
- The function returns a list of integers where each element represents the accuracy of the corresponding guess:
  - `0` if the guess is correct.
  - The absolute difference between the guess and the actual score if the guess is incorrect.
- Edge cases:
  - Empty lists: Return an empty list.
  - Lists with negative numbers: Handle these as part of the absolute difference calculation.
  - Lists with zeros: Correct guesses of zero are represented as `0`.
