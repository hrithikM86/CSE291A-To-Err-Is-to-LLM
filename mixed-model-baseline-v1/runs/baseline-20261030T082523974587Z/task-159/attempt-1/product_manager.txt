Requirements:
- Implement the `eat` function that takes three parameters: `number` (integer), `need` (integer), and `remaining` (integer).
- Return a list containing two elements: the total number of carrots eaten after the meal and the number of carrots left.
- If there are not enough remaining carrots to satisfy the need, eat all remaining carrots.
- Follow the provided examples for correct behavior.
- Ensure input constraints: `0 <= number <= 1000`, `0 <= need <= 1000`, `0 <= remaining <= 1000`.

Edge Cases:
- `remaining` is 0: Eat all `number` and `need` carrots, leaving 0.
- `need` is 0: Return `[number, remaining]`.
- `number` and `need` sum to more than `remaining`: Eat all `remaining` carrots.
