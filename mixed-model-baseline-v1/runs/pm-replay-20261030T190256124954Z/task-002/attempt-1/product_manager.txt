Requirements:
- **Input**: A single parameter `number` (float).
- **Output**: A float representing the decimal part of the input number.
- **Behavior**:
  - The function should return the decimal part of the given positive floating-point number.
  - The integer part of the number should be discarded.
- **Edge Cases**:
  - If the input is a negative number, return the decimal part as is (negative).
  - If the input is an integer (no decimal part), return 0.0.
  - If the input is 0.0, return 0.0.
