### Implementation Checklist for `parse_nested_parens`

1. **Function Signature**
   ```python
   from typing import List

   def parse_nested_parens(paren_string: str) -> List[int]:
       pass
   ```

2. **Initialization**
   - Initialize an empty list `depths` to store the maximum depths.

3. **Input Validation**
   - Check if `paren_string` is empty. If so, return `depths` (an empty list).

4. **Split Input String**
   - Split `paren_string` by spaces to get individual groups.

5. **Process Each Group**
   - For each group:
     1. Initialize `current_depth` to 0.
     2. Initialize `max_depth` to 0.
     3. Iterate through each character in the group:
        - If character is '(', increment `current_depth` and update `max_depth` if `current_depth` is greater.
        - If character is ')', decrement `current_depth`.
     4. Append `max_depth` to `depths`.

6. **Return Result**
   - Return `depths`.

7. **Edge Cases**
   - Handle groups with no parentheses by returning 0 for such groups.
   - Handle unbalanced parentheses by raising a `ValueError`.

8. **Complexity**
   - Time: O(n * m), where n is the number of groups and m is the average length of a group.
   - Space: O(n), for storing the depths of each group.

9. **Testing**
   - Test with various inputs, including edge cases like empty strings, groups with no parentheses, and unbalanced parentheses.
