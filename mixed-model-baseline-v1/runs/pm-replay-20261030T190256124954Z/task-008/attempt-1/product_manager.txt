Requirements:
- **Inputs**: A list of integers (`numbers`).
- **Outputs**: A tuple containing two elements: the sum and the product of all integers in the list.
- **Behavior**:
  - If the list is empty, return `(0, 1)`.
  - For a non-empty list, calculate the sum and product of all integers.
- **Edge Cases**:
  - An empty list should return `(0, 1)`.
  - Lists containing zero should handle the product correctly (e.g., `[0, 1, 2]` should return `(3, 0)`).
