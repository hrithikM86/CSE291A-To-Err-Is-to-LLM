Requirements:
- The function `all_prefixes` takes a single input `string` (type: `str`).
- It returns a list of strings containing all prefixes of the input string, ordered from shortest to longest.
- The input string can be any valid string, including empty strings and strings with special characters.
- Edge cases:
  - If the input string is empty, return an empty list.
  - If the input string is a single character, return a list containing the string and an empty string.
- Example:
  - `all_prefixes('abc')` returns `['a', 'ab', 'abc']`.
  - `all_prefixes('')` returns `[]`.
  - `all_prefixes('x')` returns `['', 'x']`.
