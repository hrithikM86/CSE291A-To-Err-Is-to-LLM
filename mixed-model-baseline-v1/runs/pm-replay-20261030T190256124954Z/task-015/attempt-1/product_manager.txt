Requirements:
- The function `string_sequence` takes an integer `n` as input.
- It returns a string containing space-delimited numbers starting from 0 up to and including `n`.
- The input `n` must be a non-negative integer.
- For `n = 0`, the output should be the string `'0'`.
- For `n = 5`, the output should be the string `'0 1 2 3 4 5'`.
- Handle cases where `n` is a large number without performance issues.
- Ensure the function works correctly for the minimum and maximum possible integer values.
