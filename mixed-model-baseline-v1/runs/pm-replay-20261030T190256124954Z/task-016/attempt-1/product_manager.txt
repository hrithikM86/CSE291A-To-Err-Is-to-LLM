Requirements:
- **Input**: A single string `string` of alphanumeric characters.
- **Output**: An integer representing the count of distinct characters in the string, ignoring case sensitivity.
- **Behavior**:
  - Convert the string to lowercase to ensure case insensitivity.
  - Use a set to track unique characters.
  - Return the size of the set as the result.
- **Edge Cases**:
  - Empty string: Return 0.
  - String with only one character: Return 1.
  - String with all characters being the same: Return 1.
  - String with only spaces: Return 0.
