Algorithm for `parse_music`:

1. Initialize an empty list `durations` to store the result.
2. Iterate through each character in `music_string`:
   - If the character is 'o', append 4 to `durations`.
   - If the character is 'o|', append 2 to `durations`.
   - If the character is '.|', append 1 to `durations`.
   - Ignore any other characters.
3. Return `durations`.

Edge cases:
- If `music_string` is empty, return an empty list.
- If `music_string` contains invalid characters, ignore them and continue parsing the valid ones.

Complexity:
- Time: O(n), where n is the length of `music_string`.
- Space: O(m), where m is the number of valid notes in `music_string`.
