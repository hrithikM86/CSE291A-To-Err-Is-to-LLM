Algorithm for `how_many_times`:

1. **Input Validation**: Check if `string` is empty. If true, return 0.
2. **Initialization**: Set `count` to 0.
3. **Loop Through String**: Iterate through `string` using a sliding window of size equal to `substring` length.
   - For each position `i` in `string`:
     - Extract a substring of length equal to `substring` starting from `i`.
     - If this substring matches `substring`, increment `count`.
4. **Return Count**: After the loop, return `count`.

Edge Cases:
- `string` is very long, handle efficiently to avoid performance issues.
- `substring` is empty, which should return 0.
- `substring` is longer than `string`, which should return 0.

Complexity:
- Time: O(n * m) where `n` is the length of `string` and `m` is the length of `substring`.
- Space: O(1) as no additional space is used other than a few variables.
