Requirements:
- The function `how_many_times` takes two inputs: `string` (a str) and `substring` (a str).
- It returns an integer representing how many times `substring` occurs in `string`, including overlapping occurrences.
- If `string` is empty, return 0.
- Test cases:
  - `how_many_times('', 'a')` returns `0`
  - `how_many_times('aaa', 'a')` returns `3`
  - `how_many_times('aaaa', 'aa')` returns `3`
