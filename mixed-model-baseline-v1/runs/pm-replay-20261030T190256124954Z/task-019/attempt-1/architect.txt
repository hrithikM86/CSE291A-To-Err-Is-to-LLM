Algorithm:

1. Define the function `sort_numbers(numbers: str) -> str`.
2. Handle edge cases:
   - If `numbers` is an empty string, return an empty string.
3. Create a dictionary to map number words to their numerical values:
   - `{'zero': 0, 'one': 1, 'two': 2, 'three': 3, 'four': 4, 'five': 5, 'six': 6, 'seven': 7, 'eight': 8, 'nine': 9}`
4. Split the input string into a list of number words.
5. Filter out any invalid number words.
6. Convert the valid number words to their numerical values, sort them.
7. Convert the sorted numerical values back to number words.
8. Join the sorted number words with spaces and return the result.

Complexity:
- Time: O(n + m log m), where n is the number of words and m is the number of valid words.
- Space: O(n), for storing the list of number words and their sorted values.

This algorithm ensures correct sorting and handles edge cases as specified.
