Requirements:
- **Inputs**: A list of `float` numbers with at least two elements.
- **Outputs**: A list of `float` numbers where the smallest number in the input list is transformed to 0 and the largest number is transformed to 1.
- **Behavior**: Apply a linear transformation to scale the numbers in the list.
- **Edge Cases**:
  - The input list must contain at least two elements.
  - The input list can contain duplicate values.
  - The input list can include negative numbers.
  - The input list can include zero.
