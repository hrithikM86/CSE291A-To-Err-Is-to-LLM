Requirements for the `is_prime` function:

- **Input**: A single integer `n` (where `n` is a non-negative integer).
- **Output**: A boolean value (`True` or `False`).
- **Behavior**:
  - Return `True` if `n` is a prime number.
  - Return `False` if `n` is not a prime number.
- **Edge Cases**:
  - `n` = 0: Return `False`.
  - `n` = 1: Return `False`.
  - `n` = 2: Return `True` (2 is the smallest prime number).
  - `n` < 0: Not applicable as input is restricted to non-negative integers.
