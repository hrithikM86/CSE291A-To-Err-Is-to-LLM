Requirements:
- `poly(xs: list, x: float)` takes a list of coefficients `xs` and a point `x`, and returns the value of the polynomial at `x`.
- `find_zero(xs: list)` takes a list of coefficients `xs` (with an even number of elements) and returns a single zero point of the polynomial.
- The polynomial is defined by `xs[0] + xs[1] * x + xs[2] * x^2 + ... + xs[n] * x^n`.
- `find_zero` guarantees a solution due to the properties of the coefficients.
- The function should handle edge cases where the polynomial might not have real roots.
- The returned value should be rounded to 2 decimal places for consistency with the examples.
