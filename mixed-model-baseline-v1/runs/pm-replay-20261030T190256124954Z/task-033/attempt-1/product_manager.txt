Requirements:
- The function `sort_third` takes a single input `l` which is a list.
- It returns a new list `l'` where the elements at indices not divisible by three remain unchanged.
- The elements at indices divisible by three are sorted in ascending order.
- The function should handle lists of any length, including empty lists.
- Edge cases to consider:
  - An empty list should return an empty list.
  - Lists with fewer than three elements should return the list unchanged.
  - Lists with elements at indices divisible by three should sort those elements correctly.
