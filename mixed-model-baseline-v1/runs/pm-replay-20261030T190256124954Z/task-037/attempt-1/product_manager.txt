Requirements:
- The function `sort_even` takes a single input `l` which is a list of integers.
- It returns a new list `l'` where the elements at odd indices remain the same as in the original list, while the elements at even indices are sorted in ascending order.
- The function should handle lists of any length, including empty lists.
- Edge cases to consider:
  - An empty list should return an empty list.
  - A list with only one element should return the same list.
  - A list with even length should have its even-indexed elements sorted.
