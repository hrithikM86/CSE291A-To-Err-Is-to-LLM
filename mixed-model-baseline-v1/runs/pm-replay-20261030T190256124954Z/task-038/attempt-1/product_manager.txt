Requirements:
- `encode_cyclic(s: str)` should take a string `s` as input.
- The function should split the string into groups of three characters.
- If a group has exactly three characters, cyclically shift it by moving the first character to the end.
- If a group has fewer than three characters, leave it unchanged.
- Join the modified groups back into a single string and return it.
- `decode_cyclic(s: str)` should take an encoded string as input, which was encoded using `encode_cyclic`.
- The function should reverse the encoding process to return the original string.
- Handle edge cases where the input string is empty or has less than three characters.
