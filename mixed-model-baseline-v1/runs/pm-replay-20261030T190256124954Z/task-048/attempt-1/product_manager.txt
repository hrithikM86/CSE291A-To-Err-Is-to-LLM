Requirements:
- **Input**: A single string `text` of any length.
- **Output**: A boolean value indicating whether `text` is a palindrome.
- **Behavior**:
  - Return `True` if `text` reads the same backward as forward.
  - Return `False` otherwise.
- **Edge Cases**:
  - An empty string should return `True`.
  - Case sensitivity: treat uppercase and lowercase letters as equal.
  - Ignore non-alphanumeric characters.
