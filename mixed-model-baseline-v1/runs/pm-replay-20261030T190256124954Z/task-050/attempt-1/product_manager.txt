Requirements for `encode_shift`:
- Input: `s` (a string)
- Output: A string where each character in `s` is shifted 5 positions forward in the alphabet.
- Behavior: Use modulo arithmetic to wrap around the alphabet if necessary.
- Edge Cases: Handle non-alphabetic characters by leaving them unchanged.

Requirements for `decode_shift`:
- Input: `s` (a string encoded with `encode_shift`)
- Output: A string where each character in `s` is shifted 5 positions backward in the alphabet.
- Behavior: Use modulo arithmetic to wrap around the alphabet if necessary.
- Edge Cases: Handle non-alphabetic characters by leaving them unchanged.
