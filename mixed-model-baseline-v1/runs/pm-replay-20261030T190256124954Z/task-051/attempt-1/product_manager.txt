Requirements:
- The function `remove_vowels` takes a single input `text` (a string).
- It returns a new string with all vowels removed.
- The function should handle an empty string input, returning an empty string.
- Vowels include 'a', 'e', 'i', 'o', 'u' (both uppercase and lowercase).
- The function should preserve the original case of the consonants.
- Whitespace and non-alphabetic characters should remain unchanged.
- Edge cases: 
  - Empty string: Return ''.
  - String with only vowels: Return ''.
  - String with no vowels: Return the original string.
