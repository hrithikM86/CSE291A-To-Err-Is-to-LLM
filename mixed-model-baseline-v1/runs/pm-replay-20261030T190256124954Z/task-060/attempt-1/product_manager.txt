Requirements for `sum_to_n(n: int)`:

- **Input**: A single integer `n` (1 ≤ n ≤ 10000).
- **Output**: An integer representing the sum of all numbers from 1 to `n`.
- **Behavior**:
  - Use the formula for the sum of the first `n` natural numbers: `n * (n + 1) // 2`.
  - Ensure the function handles edge cases, such as `n = 1`, correctly.
- **Edge Cases**:
  - `n = 1` should return `1`.
  - `n` within the range [1, 10000] should return the correct sum.
  - `n` outside the range should not be handled as the function is constrained to this range.
