Requirements for `vowels_count(s)`:

- **Input**: A single string `s` representing a word.
- **Output**: An integer representing the number of vowels in the string `s`.
- **Behavior**:
  - Count 'a', 'e', 'i', 'o', 'u' as vowels.
  - Count 'y' as a vowel only if it is the last character of the string.
- **Edge Cases**:
  - Empty string: Returns 0.
  - String with no vowels: Returns 0.
  - String ending with 'y': Counts 'y' as a vowel.
  - String with only vowels: Returns the length of the string.
  - String with mixed vowels and consonants: Correctly counts vowels including 'y' at the end.
