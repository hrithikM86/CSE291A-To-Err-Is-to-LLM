Algorithm for `strange_sort_list(lst)`:

1. **Input Validation**: Check if the input list `lst` is empty. If it is, return an empty list.
2. **Initialization**: 
   - Create an empty result list `result`.
   - Create a copy of the input list `lst` to keep track of remaining elements.
3. **Sorting Logic**:
   - While `lst` is not empty:
     - Find the minimum value in `lst` and append it to `result`.
     - Remove the minimum value from `lst`.
     - If `lst` is not empty, find the maximum value in `lst` and append it to `result`.
     - Remove the maximum value from `lst`.
4. **Return Result**: Return the `result` list.

**Edge Cases**:
- An empty list should return an empty list.
- A list with duplicate values should handle them as per the described sorting logic (e.g., `[1, 1, 2, 2]` should result in `[1, 2, 1, 2]`).
- The list can contain both positive and negative integers, which will be handled by the min and max functions.

**Complexity**:
- Time Complexity: O(n^2) due to the repeated search for min and max in each iteration.
- Space Complexity: O(n) for the result list and the copy of the input list.
