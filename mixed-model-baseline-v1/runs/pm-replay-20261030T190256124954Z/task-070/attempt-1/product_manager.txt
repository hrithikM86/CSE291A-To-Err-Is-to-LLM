Requirements:
- **Inputs**: A list of integers (`lst`).
- **Outputs**: A list of integers sorted in a "strange" order as described.
- **Behavior**:
  - Start with the minimum value in the list.
  - Then select the maximum of the remaining integers.
  - Continue alternating between the minimum and maximum of the remaining elements until the list is exhausted.
- **Edge Cases**:
  - An empty list should return an empty list.
  - A list with duplicate values should handle them as per the described sorting logic.
  - The list can contain both positive and negative integers.
