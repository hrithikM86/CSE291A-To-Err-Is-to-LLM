Requirements:
- **Inputs**: A non-empty list of integers (`lst`).
- **Outputs**: An integer representing the sum of even elements located at odd indices in the list.
- **Behavior**:
  - Traverse the list, considering only elements at odd indices (1st, 3rd, 5th, etc.).
  - Check if the element at each odd index is even.
  - Sum up all even elements found at odd indices.
- **Edge Cases**:
  - If there are no even elements at odd indices, return 0.
  - Ensure the list is non-empty; if not, raise an appropriate error.
