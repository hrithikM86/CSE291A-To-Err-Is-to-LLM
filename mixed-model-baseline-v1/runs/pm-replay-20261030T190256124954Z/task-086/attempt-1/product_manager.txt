Requirements:
- The function `anti_shuffle(s)` takes a single string `s` as input.
- It returns a new string where each word in the input string is replaced by a new word formed by sorting the characters of the original word in ascending ASCII order.
- The order of words and spaces in the sentence must be preserved.
- The function should handle punctuation and maintain its position relative to the words.
- Edge cases:
  - Empty string: Returns an empty string.
  - Single word: Returns the sorted word.
  - Punctuation: Preserves punctuation attached to words.
  - Multiple spaces: Handles multiple spaces between words correctly.
