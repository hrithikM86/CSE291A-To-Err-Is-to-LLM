Requirements:
- Input: A string `S` containing words separated by spaces.
- Output: An integer representing the number of sentences starting with "I".
- Sentences are delimited by '.', '?', or '!'.
- Consider case sensitivity; "I" should match exactly.
- Edge cases:
  - Empty string: Return 0.
  - No sentences starting with "I": Return 0.
  - Multiple delimiters: Handle correctly (e.g., "I!I?I").
  - Leading or trailing punctuation: Handle correctly (e.g., "I. I?").
