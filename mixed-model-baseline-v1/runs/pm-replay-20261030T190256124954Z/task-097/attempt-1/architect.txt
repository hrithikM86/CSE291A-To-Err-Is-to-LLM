Algorithm for `multiply(a, b)`:

1. Extract the unit digit of `a` by computing `a % 10`.
2. Extract the unit digit of `b` by computing `b % 10`.
3. Multiply the two unit digits.
4. Return the result.

Edge cases:
- If either `a` or `b` is 0, return 0.
- Handle negative numbers by ensuring the unit digits are positive before multiplication.

Complexity:
- Time complexity: O(1) - The operations are constant time.
- Space complexity: O(1) - No additional space is used.
