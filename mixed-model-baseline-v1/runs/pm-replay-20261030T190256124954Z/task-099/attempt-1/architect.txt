Algorithm for `closest_integer(value)`:

1. Validate input:
   - Check if `value` is a valid numeric string.
   - If not, return `None` or raise an error.

2. Convert `value` to a float.

3. Determine the closest integers:
   - Calculate the floor and ceiling of the float value.
   - If the difference between the float value and the floor is exactly 0.5, choose the ceiling.
   - If the difference between the float value and the ceiling is exactly 0.5, choose the floor.

4. Return the chosen integer.

Edge cases:
- Empty string: Return `None` or raise an error.
- Non-numeric string: Return `None` or raise an error.
- Very large or very small numbers: Ensure no overflow or underflow occurs.

Complexity:
- Input validation: O(1)
- Conversion and calculation: O(1)
- Total: O(1)
