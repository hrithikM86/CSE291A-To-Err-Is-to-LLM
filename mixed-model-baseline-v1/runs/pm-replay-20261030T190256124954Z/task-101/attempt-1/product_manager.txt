Requirements:
- The function `words_string(s)` takes a single input `s`, a string containing words separated by commas or spaces.
- The function should return a list of words extracted from the input string.
- Words are considered to be sequences of characters separated by commas or spaces.
- The function should handle multiple consecutive commas or spaces correctly.
- Edge cases:
  - Empty string input should return an empty list.
  - Input with only spaces or commas should be handled correctly.
  - Input with special characters or punctuation other than commas or spaces should be ignored.
