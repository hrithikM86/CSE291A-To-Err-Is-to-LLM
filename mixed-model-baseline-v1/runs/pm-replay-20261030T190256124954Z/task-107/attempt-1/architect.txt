Algorithm:

1. Define a helper function `is_palindrome(num)` to check if a number is a palindrome.
2. Initialize counters `even_count` and `odd_count` to 0.
3. Iterate through each number `i` from 1 to `n` (inclusive).
4. For each `i`, if `is_palindrome(i)` is true:
   - Increment `even_count` if `i` is even.
   - Increment `odd_count` if `i` is odd.
5. Return the tuple `(even_count, odd_count)`.

Edge Cases:
- If `n` is 1, return (0, 1).
- If `n` is 2, return (1, 1).

Complexity:
- The `is_palindrome` function has a complexity of O(log n) since it checks each digit.
- The loop runs `n` times, so the overall complexity is O(n log n).
