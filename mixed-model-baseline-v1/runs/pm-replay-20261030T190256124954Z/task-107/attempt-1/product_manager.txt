Requirements:
- **Inputs**: A positive integer `n` (1 ≤ n ≤ 10^3).
- **Outputs**: A tuple containing two integers: the first integer represents the count of even integer palindromes, and the second integer represents the count of odd integer palindromes within the range(1, n), inclusive.
- **Behavior**:
  - Count all integer palindromes within the given range.
  - Separate the count into even and odd palindromes.
- **Edge Cases**:
  - If `n` is 1, return (0, 1) since 1 is an odd palindrome.
  - If `n` is 2, return (1, 1) since 1 and 2 are the only palindromes, and 1 is odd, 2 is even.
