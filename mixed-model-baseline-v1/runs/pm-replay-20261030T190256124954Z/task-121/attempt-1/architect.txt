Algorithm:

1. Initialize `sum` to 0.
2. Iterate through the list `lst` using an index-based loop, starting from index 0 and incrementing by 2 (to consider only even indices).
3. For each element at the current index:
   - Check if the element is odd.
   - If it is odd, add it to `sum`.
4. After the loop, return `sum`.

Edge Cases:
- If the list has only one element, check if it is odd and return it if true, otherwise return 0.
- If there are no odd elements at even indices, return 0.

Complexity:
- Time Complexity: O(n), where n is the length of the list.
- Space Complexity: O(1), as only a single variable (`sum`) is used.
