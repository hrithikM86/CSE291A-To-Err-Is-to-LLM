Algorithm:

1. **Input Validation**: Check if the list is empty or contains a single element. If so, return `True`.
2. **Iterate Through List**: Loop through the list from the first element to the second last element.
   - For each element, compare it with the next element.
   - If the current element is greater than the next element, return `False`.
   - If the current element is equal to the next element, return `False` (as per the requirement).
3. **Return True**: If the loop completes without returning `False`, return `True`.

Edge Cases:
- An empty list.
- A list with a single element.
- Consecutive duplicates (e.g., `[1, 1, 2, 3]`).
- A list that is already sorted in ascending order.

Complexity:
- Time Complexity: O(n), where n is the length of the list.
- Space Complexity: O(1), as no additional space is used other than variables for iteration.
