Algorithm:

1. Check if the input array `arr` is empty.
   - If empty, return `None`.
2. Initialize `sign_product` to 1 and `magnitude_sum` to 0.
3. Iterate through each integer `num` in `arr`:
   - If `num` is 0:
     - Set `sign_product` to 0 and break the loop.
   - Otherwise:
     - Multiply `sign_product` by the sign of `num` (1 if positive, -1 if negative).
     - Add the magnitude of `num` to `magnitude_sum`.
4. Multiply `magnitude_sum` by `sign_product`.
5. Return the result.

Edge Cases:
- Handling an empty array by returning `None`.
- Properly handling zeros, as they set the `sign_product` to 0.
- Correctly handling both positive and negative numbers.

Complexity:
- Time: O(n), where n is the length of the array.
- Space: O(1), constant space used.
