Requirements:
- **Input**: A list of unique integers (`arr`).
- **Output**: An integer representing the largest index of an element that is not greater than or equal to the element immediately preceding it. If no such element exists, return -1.
- **Behavior**:
  - Traverse the list from the end to the beginning.
  - Compare each element with its preceding element.
  - Return the index of the first element that does not satisfy the condition (i.e., is greater than the previous element).
  - If no such element is found, return -1.
- **Edge Cases**:
  - An empty list should return -1.
  - A list with a single element should return -1.
  - A list in strictly increasing order should return -1.
