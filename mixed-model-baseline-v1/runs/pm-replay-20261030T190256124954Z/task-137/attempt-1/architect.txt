Algorithm for `compare_one(a, b)`:

1. **Input Validation**: Ensure both `a` and `b` are either integers, floats, or strings. If not, return `None`.

2. **Type Handling**:
   - If both `a` and `b` are integers or floats, directly compare them and return the larger one.
   - If one is a string and the other is a number, convert the string to a float, handling both `.` and `,` as decimal separators.
   - If both are strings, convert both to floats and compare.

3. **Equality Check**: If the values are equal after conversion, return `None`.

4. **Return Result**: Return the larger value in its original type or `None` if they are equal.

Edge Cases:
- Both values are equal: Return `None`.
- One value is a string and the other is a number: Convert the string to a float.
- Invalid input types: Return `None`.

Complexity:
- Time: O(1) for basic comparisons and conversions.
- Space: O(1) for storing input and temporary variables.

This algorithm ensures correct handling of different input types and edge cases as specified.
