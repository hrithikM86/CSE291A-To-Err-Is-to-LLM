Algorithm for `file_name_check(file_name)`:

1. **Check for Empty String**: If `file_name` is empty, return 'No'.
2. **Count Digits**: Count the number of digits in `file_name`. If the count is greater than 3, return 'No'.
3. **Count Dots**: Count the number of dots in `file_name`. If the count is not exactly 1, return 'No'.
4. **Split by Dot**: Split `file_name` by the dot. Ensure there are exactly two parts: before and after the dot.
5. **Validate Prefix**: Check if the first part (before the dot) starts with a letter (a-z or A-Z) and is not empty. If not, return 'No'.
6. **Validate Suffix**: Check if the second part (after the dot) is one of ['txt', 'exe', 'dll']. If not, return 'No'.
7. **Return Valid**: If all checks pass, return 'Yes'.

**Complexity**:
- The algorithm has a time complexity of O(n) where n is the length of the file name, due to the string operations and checks.
- The space complexity is O(1) as it uses a fixed amount of additional space.
