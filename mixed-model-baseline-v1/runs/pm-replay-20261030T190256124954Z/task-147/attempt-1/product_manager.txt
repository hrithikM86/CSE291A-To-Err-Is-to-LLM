Requirements:
- Implement `get_max_triples(n)`.
- `n` is a positive integer.
- Generate an array `a` of length `n` where `a[i] = i * i - i + 1` for `1 ≤ i ≤ n`.
- Return the number of triples `(a[i], a[j], a[k])` with `i < j < k` such that `a[i] + a[j] + a[k]` is a multiple of 3.
- Handle edge cases where `n` is less than 3, in which case no triples can be formed, so return 0.

Example:
- Input: `n = 5`
- Output: `1`
- Explanation: `a = [1, 3, 7, 13, 21]`, valid triple: `(1, 7, 13)`.
