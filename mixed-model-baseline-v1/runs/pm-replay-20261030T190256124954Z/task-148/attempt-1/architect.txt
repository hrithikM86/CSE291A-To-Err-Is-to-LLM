Algorithm:

1. Define a list of planets sorted by their proximity to the Sun: `planets = ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune"]`.
2. Validate `planet1` and `planet2`:
   - If either is not in the list of planets, return an empty tuple `()`.
3. Find the indices of `planet1` and `planet2` in the `planets` list.
4. Ensure `planet1` comes before `planet2` by swapping indices if necessary.
5. Return a tuple of planets between the indices (inclusive of `planet1` and exclusive of `planet2`).

Edge Cases:
- If `planet1` and `planet2` are the same, return an empty tuple.
- If `planet1` or `planet2` is not a valid planet name, return an empty tuple.

Complexity:
- The validation and index finding steps are O(1) since the number of planets is fixed.
- The slicing operation to return the tuple is O(n), where n is the number of planets between `planet1` and `planet2`.
