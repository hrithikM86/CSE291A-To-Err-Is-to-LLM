Algorithm:

1. Initialize `sum_of_squares` to 0.
2. Iterate through each number `num` in `lst`:
   - If `num` is an integer, non-negative, and odd:
     - Square `num` and add the result to `sum_of_squares`.
3. After iterating through the list, return `sum_of_squares`.

Edge Cases:
- If the list is empty, return 0.
- If the list contains no valid numbers (non-negative, non-negative integers, and odd), return 0.

Complexity:
- Time Complexity: O(n), where n is the length of the list.
- Space Complexity: O(1), as we are using a constant amount of extra space.
