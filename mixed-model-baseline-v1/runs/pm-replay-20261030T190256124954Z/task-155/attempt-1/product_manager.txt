Requirements:
- **Input**: A single integer `num`.
- **Output**: A tuple containing two integers: the first integer represents the count of even digits, and the second integer represents the count of odd digits in `num`.
- **Behavior**:
  - Handle both positive and negative integers.
  - Consider the sign as a digit if the number is negative.
  - Include leading zeros if the number is represented with them (though unlikely in practice).
- **Edge Cases**:
  - If `num` is `0`, return `(1, 0)` since `0` is even.
  - If `num` is negative, treat the minus sign as a digit and include it in the count if applicable.
  - Handle very large numbers efficiently.
