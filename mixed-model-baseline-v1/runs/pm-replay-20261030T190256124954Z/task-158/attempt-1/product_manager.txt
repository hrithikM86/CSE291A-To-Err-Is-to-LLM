Requirements:
- **Input**: A list of strings (`words`).
- **Output**: A string representing the word with the maximum number of unique characters. If there are multiple such words, return the one that comes first lexicographically.
- **Behavior**:
  - Count the unique characters in each word.
  - Return the word with the highest unique character count.
  - In case of a tie, return the word that is lexicographically smallest.
- **Edge Cases**:
  - Empty list: Return `None` or raise an appropriate error.
  - List with only one word: Return that word.
  - List with words of the same length and unique character count: Return the lexicographically smallest word.
